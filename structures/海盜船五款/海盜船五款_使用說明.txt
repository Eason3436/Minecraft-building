海盜船五款 — Minecraft 基岩版結構行為包（v1.0.0）

【簡介】
一個行為包裡有五艘不同風格的小型海盜船，每艘的寬、深都在 50 格以內，設計成直接放在海面上。
五艘都可以走進去：船長室、砲甲板、貨艙用梯子上下相通，內部擺滿家具、寶箱、燈與雜物。
附圖：海盜船五款_整體渲染.png（五艘外觀）、海盜船五款_內部剖視.png（每艘按甲板分層拆開）。
附圖是依方塊資料繪製的示意圖，不是遊戲截圖。

【匯入與啟用】
1. 開啟（雙擊）海盜船五款.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立或編輯世界 → 行為包 → 啟用「海盜船五款」。
3. 世界要開啟「作弊」（指令），建議創造模式。

【放在海上：高度怎麼算】
每艘船的水線都在結構本地 Y=5（那一格是海面的水）。
主世界海面是 Y=62，所以結構原點的 Y 要用 57。原點是結構的最小 X/Y/Z 角（船的左前下角），不是船中心。
船首朝北（−Z），船尾朝南（+Z）。請選水深至少 7 格的開闊海面。

【放一艘】（把 X、Z 換成你要的位置，Y 保持 57）
  /execute positioned X 57 Z run function pirate/black_skull
  /execute positioned X 57 Z run function pirate/swift_sloop
  /execute positioned X 57 Z run function pirate/crimson_brig
  /execute positioned X 57 Z run function pirate/ghost_ship
  /execute positioned X 57 Z run function pirate/red_junk
也可以直接用結構指令，例如：
  /structure load pirate_261103:black_skull 100 57 100
或用結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入上面的完整 ID（旋轉 0°、不鏡像、完整性 100%）。

【一次放五艘（艦隊）】
五艘沿 +X 方向並排，間隔 6 格，整排約 131 × 50 格：
  /execute positioned 0 57 0 run function pirate/fleet_prepare
  （等 3～5 秒讓區塊載入）
  /execute positioned 0 57 0 run function pirate/fleet
  /function pirate/fleet_cleanup
  /execute positioned 0 57 0 run function pirate/fleet_view   → 傳送到船隊前方空中看全景
各艘的 X 偏移：黑骷髏號 0、疾風號 +31、赤焰號 +54、亡靈號 +81、紅旗號 +110（Y、Z 偏移都是 0）。
若有一艘沒出現，通常是區塊還沒載入：站近一點再執行一次 fleet（重複載入不會壞）。

【怎麼進船艙】
主甲板中間靠主桅的地方有梯子，可一路下到砲甲板和貨艙。
船長室在船尾，門朝船頭；艉樓兩側有樓梯上舵輪甲板。黑骷髏號船長室裡還有一條私人梯子通往寶藏室。
疾風號只有一層貨艙，梯子在桅杆前面；船長小艙在船尾，旁邊的樓梯可上艙頂。

【注意】
- 船外的空間存成「結構空位」，放置時不會清掉海水；船殼裡面存成空氣，所以船艙是乾的。
  水線以下的船殼已檢查沒有破口，不會進水（亡靈號貨艙的積水是設計好的，四周有船殼包住，不會流出）。
- 船殼、甲板與帆所在的位置會覆蓋原本的方塊，請選空的海面。
- 寶箱已預先放入戰利品（金錠、綠寶石、鑽石、金蘋果等）；其他桶子與箱子大多是空的。
- 床有顏色資料（紅、藍、黑等），可以睡；舵輪、砲、錨、小艇都是造型，不會動、不會開火。
- 亡靈號沒有放真的火；靈魂營火與營火不會點燃木頭。
- 晚上看效果最好（燈籠、靈魂燈、蕈光、蠟燭會亮）。
- 不要在結構方塊按「儲存」覆蓋同名結構；只要匯入行為包，不需要替換 db 或世界檔。
- 這是基岩版行為包，不是 Java 版 schematic，也不是完整世界。
