沖繩美麗海水族館園區 — Minecraft 基岩版結構行為包（v1.0.0）

【簡介】
還原沖繩本部町「海洋博公園」與園區中央的「沖繩美麗海水族館」（2002 年開館，4 層樓鋼骨鋼筋混凝土）。
水族館照官方樓層圖的參觀動線建造，平面約 1 格 = 1 公尺；大水槽「黑潮之海」做成 27 × 37 × 10 格（真實 27 × 35 × 10 m），
觀賞面 22 × 8 格（真實 22.5 × 8.2 m）。所有水槽都有真的水、底沙、岩礁、珊瑚／海草／海帶等植物、照明，
遊戲裡有的生物用真的生物（235 隻），遊戲裡沒有的（鯨鯊、鬼蝠魟、鯊魚、海牛）用方塊雕像。
園區其他設施（劇場、海龜館、海牛館、海灘、溫室…）按真實相對位置排列，但彼此的距離壓縮約 1/4。
附圖：沖繩美麗海水族館園區_整體渲染.png、沖繩美麗海水族館園區_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。

【尺寸與方位】
寬 256 × 深 448 × 高 64 格（X=256、Y=64、Z=448）。西側（−X）是東海，北為 −Z。
切成 4 × 7 共 28 個分件，每件 X64 × Y64 × Z64。
以結構原點為 (0,0,0)：海面 Y+7，海景廣場與劇場 Y+9，水族館 1F 地板 Y+9、2F Y+16、3F Y+23、4F 屋頂廣場與中央門台地 Y+30，
南側台地（熱帶夢幻中心、鄉土村）Y+18。水族館本體在 X 94～205、Z 114～236。

【匯入與啟用】
1. 開啟（雙擊）沖繩美麗海水族館園區.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立或編輯世界 → 行為包 → 啟用「沖繩美麗海水族館園區」。
3. 世界要開啟「作弊」（指令）。建議用超平坦世界，需要 256 × 448 的空地。

【一鍵放置（建議）】
以原點 0 -61 0（超平坦世界：最底層剛好取代草地）為例，依序執行：
  /execute positioned 0 -61 0 run function churaumi/prepare
  （等 5～10 秒讓 5 個常駐區域載入）
  /execute positioned 0 -61 0 run function churaumi/build
  /execute positioned 0 -61 0 run function churaumi/animals     ← 放入真實生物（只能執行一次）
  /function churaumi/cleanup
參觀（傳送）：
  /execute positioned 0 -61 0 run function churaumi/tour           → 中央門（兩隻大風獅爺）
  /execute positioned 0 -61 0 run function churaumi/tour_gate      → 海人門與鯨鯊雕像（4F 入口）
  /execute positioned 0 -61 0 run function churaumi/tour_coral     → 3F 珊瑚之海觀賞廊
  /execute positioned 0 -61 0 run function churaumi/tour_kuroshio  → 2F 黑潮之海觀覽席（面對大觀賞面）
  /execute positioned 0 -61 0 run function churaumi/tour_theater   → 歐奇劇場觀眾席
  /execute positioned 0 -61 0 run function churaumi/tour_beach     → 翡翠海灘
想移除所有生物：/function churaumi/clear_animals
※ 一般主世界請把 0 -61 0 換成你要的地面座標（例如 0 60 0）。若某一塊沒出現，飛近一點再執行一次 build。
※ 生物都有名牌，不會自然消失。

【逐件放置（結構方塊或指令）】
取得結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入結構名稱（旋轉 0°、無鏡像）。
完整 ID：churaumi_261110:tile_x<i>_z<j>（i = 0～3、j = 0～6），放在 (X + 64i, Y, Z + 64j)。以原點 (0, -61, 0) 為例：
  /structure load churaumi_261110:tile_x0_z0 0 -61 0
  /structure load churaumi_261110:tile_x1_z0 64 -61 0
  /structure load churaumi_261110:tile_x2_z3 128 -61 192
  /structure load churaumi_261110:tile_x3_z6 192 -61 384
  …（其餘照此規則）
也可用「建築放置台」放置（啟用本包後會自動出現在選單）。放好後仍要在原點執行 churaumi/animals 才會有真實生物。

【水族館參觀路線】（館內每區都有告示牌，日文原名＋中文）
4F「大海への誘い」：中央門往北走到屋頂廣場 → 海人門（白色 A 字格樑大門）→ 鯨鯊雕像 → 「必看點」從上方俯看露天的珊瑚之海
   → 玻璃雨遮下的樓梯／手扶梯往下。西南角是餐廳「Inoh」（落地窗看東海與伊江島，白色大屋根出挑）。
3F「サンゴ礁への旅」：Coral Lobby 入口大廳（票閘、服務台、鯨鯊看板）
   → 伊諾的生物（天窗下的觸摸池：海星、海參、小魚）
   → 珊瑚之海（露天大槽，陽光直射，大量珊瑚塊、桌形珊瑚、珊瑚扇、海鞘、40 隻熱帶魚；東側與南側兩面觀賞窗）
   → 珊瑚礁之旅走廊（8 個個水槽）→ 黑潮探檢（側門出去，從水面上方看黑潮之海）
   → 熱帶魚之海（淺岩→沙地→南側暗洞窟，50 隻熱帶魚＋刺河魨）→ 珊瑚礁之部屋（危險生物小水槽、圓柱水槽）→ 珊瑚礁藝廊 → 樓梯下 2F。
2F「黒潮への旅」：美麗海劇場（銀幕＋階梯座位）→ 鯊魚博士研究室（危險鯊魚之海：虎鯊、公牛鯊、鎚頭鯊雕像；顎骨標本、書架）
   → 黑潮之海觀覽大廳：從 2F 高度一路沿階梯座位往下到大觀賞面前，
     水槽裡有 3 隻鯨鯊、5 隻鬼蝠魟、1 隻鯊魚雕像，以及鰹魚群（鱈魚）、黑鮪魚（鮭魚）、熱帶魚、海龜；
     南端「水中觀賞室」天花板是玻璃，從下往上看；北端「Ocean Blue 咖啡廳」座位就在水槽玻璃旁。
1F「深海への旅」：深層之海（暗室、玄武岩深海底、鸚鵡螺、發光魷魚）→ 深海小生物水槽 → 海之天象儀（黑暗中發光的生物）
   → Aqua Lab 深海探險之房（黃色潛水艇模型、研究桌）→ 商店「Blue Manta」→ 出口大廳（鯨鯊壁畫）→ 西側大門到海景廣場。

【園區設施】（由北到南）
- 翡翠海灘：三個弧形灣、突堤、離岸堤、白沙、陽傘與躺椅、紅瓦休息屋、椰子樹。
- 沖繩美麗海水族館（見上），西側海景廣場有椰子樹與海堤散步道。
- 歐奇劇場：面海的大池（池壁與海面同高，背景是伊江島）、舞台、跳躍吊環、扇形觀眾席與白色遮陽膜、池邊的海豚水中觀賞窗。
- 海豚潟湖：岩岸天然潟湖、木棧道、與海相通的鐵欄閘門。
- 海龜館：圓形主池、產卵沙灘、地下觀賞室。
- 海牛館：室內池、天窗、兩層挑高的大觀賞窗、紅瓦屋頂；3 隻海牛方塊雕像。
- 中央門：兩隻大風獅爺、售票亭、紅瓦大屋頂；往北的步道接水族館 4F 廣場，往西有大階梯下到海景廣場。
- 海洋文化館＋天象館：白色大屋頂館舍、圓頂天象館、館內四艘大洋洲叉架獨木舟。
- 熱帶夢幻中心：圓形水池中庭、四棟蘭花玻璃溫室、遠見之塔（外繞螺旋坡道、頂部觀景台）。
- 沖繩鄉土村：六戶琉球古民家（珊瑚石牆、屏風牆、紅瓦四坡頂、屋頂風獅爺、福木防風林）。
- 夕陽廣場、熱帶海灘、遊園車道路與沿海散步道。
- 海上的伊江島與城山（タッチュー）。

【生物】
真實生物（churaumi/animals 放入，共 235 隻，生成點都已檢查在水中）：
  熱帶魚、鱈魚（黑潮的鰹魚群、鯊魚池小魚）、鮭魚（黑鮪魚）、刺河魨、海豚 8、海龜 7、鸚鵡螺 4、發光魷魚 3。
方塊雕像：鯨鯊（館內 3＋商店 1＋4F 大雕像）、鬼蝠魟 5、虎鯊／公牛鯊／鎚頭鯊、海牛 3、風獅爺。

【已知簡化】
- 水族館平面約 1:1，但真實建築的內部隔間圖沒有公開，房間位置是依官方樓層圖的展區順序自行配置；非開放區（後場、過濾機房）以實心或簡化房間表示。
- 園區設施間距壓縮約 1/4，伊江島（真實距離約 9 km）放在近海。
- 海人門、海洋文化館外型依印象簡化；鯨鯊、鬼蝠魟是靜止的方塊雕像。
- 地圖邊緣的海水外圍放了一圈屏障方塊（看不見），避免海水流出結構範圍。

【注意】
- 結構中的空氣會清除原地方塊；請預留 256 × 448 × 64 的空間。
- 不要在結構方塊按「儲存」覆蓋同名結構；只需匯入行為包，不需更換 db 或世界檔。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。
