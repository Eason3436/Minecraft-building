紐約紅磚公寓街屋 — Minecraft 基岩版結構行為包（v1.0.1）

【簡介】
參考使用者提供的三張紐約紅磚公寓圖（正面街景、背面庭院、鳥瞰）重新設計的原創三連棟街屋，風格相近、非逐塊複製。
由街上看由左到右：
- 褐石屋 A（西）：灰色粗石半地下室、高台階大門、四層紅磚、深灰曼薩爾屋頂與老虎窗，屋頂花園，後面有鐵欄陽台，西側山牆兩支煙囪。
- 褐石屋 B（中）：深色石材基座與門框、曼薩爾屋頂，屋頂上有小閣樓（樓梯出口）與露台。
- 六層公寓 C（東）：白石腰帶、三格大窗、中央白石門框雙開大門、厚簷口；屋頂有木造水塔、樓梯機房、煙囪、冷氣機。
街景：人行道、三支路燈、花圃與鐵欄、長椅、消防栓、垃圾桶、擋車柱。
後巷：黃褐色鋪地、後院圍籬、電錶、木桶、堆肥箱、盆栽、排水管、後巷燈。
室內：每層都有樓梯可一路走到屋頂；客廳（沙發、茶几、書櫃、地毯）、臥室（床、箱子）、廚房（爐子、煙燻爐、鍋釜）、吊燈。
公寓 C 每層東西兩戶＋中央走廊，一樓是大廳與信箱。
附圖：紐約紅磚公寓街屋_整體渲染.png、紐約紅磚公寓街屋_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。

【尺寸】
寬 48 × 深 48 × 高 46 格（X=48、Y=46、Z=48），單一結構，不用分件。
方位：街道在南（+Z），正門朝南；後巷在北（-Z）。結構原點 = 西北下角。
人行道 Z=44～47，前院花圃 Z=40～43，樓前牆面 Z=39；地面層在 Y=0，人站在 Y=1。

【匯入與啟用】
1. 開啟（雙擊）紐約紅磚公寓街屋.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立或編輯世界 → 行為包 → 啟用「紐約紅磚公寓街屋」。
3. 世界要開啟「作弊」（指令）。

【放置】
方法一（建議）：可用建築放置台放置（啟用此包後，放置台選單會自動列出這座建築）。
方法二：指令（站在要放的地方附近，原點換成自己的空地）：
  /structure load nycrow_261107:rowhouses 100 64 100
  → 建築占 X 100～147、Y 64～109、Z 100～147，正門朝南（+Z）。Y 填地面那一層的高度。
方法三：結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入 nycrow_261107:rowhouses（旋轉 0°、無鏡像）。

【注意】
- 結構裡的空氣會清空原地方塊（包含 48×48×46 範圍內的地形與樹），請在空地放置。
- 水塔裡有水，四周與底部都封住，不會流出。
- 窗戶是染色玻璃板、鐵欄杆與牆的連接狀態已預先算好。
- 不要在結構方塊按「儲存」覆蓋同名結構；只需匯入行為包，不需更換 db 或世界檔。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。

【復刻辨識特徵／已簡化之處】
保留：三棟高低不同的紅磚量體、曼薩爾深灰屋頂與老虎窗、石材簷口與托架、褐石屋高台階與鐵欄、白石腰帶公寓、
公寓往後凸出形成褐石屋後院、黃褐色後巷、屋頂花園、屋頂小閣樓、排水管與電錶。
簡化／自行補上：磚牆斑駁用紅磚＋花崗岩＋磨製花崗岩混色；電錶用鐵活板門表示；參考圖沒有的水塔是加上的紐約元素；
室內完全看不到，依風格自行設計。
