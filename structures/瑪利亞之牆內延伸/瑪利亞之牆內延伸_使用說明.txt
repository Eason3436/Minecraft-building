瑪利亞之牆內延伸 — Minecraft 基岩版結構行為包（v1.0.0）

【簡介】
這是「希娜之牆內王都」「羅塞之牆內延伸」之後的第三圈：從羅塞之牆往外延伸到最外層的「瑪利亞之牆」。
內容一樣只有建築、森林、草原，不含任何人物或巨人。
這個包「不含」羅塞之牆以內：請先放好希娜包與羅塞包，再把這個包對齊放在最外圍。
瑪利亞之牆在東西南北各突出一個城區：
  南：希干希納區（主角的故鄉，呈現 845 年被攻破的樣子）
  西：昆塔區（出自小說《進擊的巨人 隔絕都市的女王》）
  東：瑪利亞東城區、北：瑪利亞北城區（原作沒有命名）
附圖：瑪利亞之牆內延伸_整體渲染.png、瑪利亞之牆內延伸_近景剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。

【比例】
  ・維持前兩包的比例：原作瑪利亞之牆半徑約 480 km、希娜之牆約 250 km，
    希娜之牆半徑 430 格，所以瑪利亞之牆半徑 430 × 480 ÷ 250 ≈ 826 格（羅塞之牆是 654 格）。
  ・牆高 50 m，房屋與建築本體都是 1 格 ＝ 1 公尺，與前兩包相同。

【尺寸】
整片範圍寬 1920 × 深 1920（X、Z），切成 30×30 個 64×64 分件。
中央 24×24 件（1536×1536）是羅塞包的範圍。羅塞包在羅塞之牆外只有填充用的草原森林，
這一包把那一圈重新做成瑪利亞之牆內的土地，所以收了：
  ・羅塞範圍以外的 324 件
  ・羅塞範圍內、羅塞之牆外側有改動的 275 件（會蓋掉羅塞包同位置的分件）
    這些分件裡羅塞之牆以內的部分，與羅塞包原本的方塊逐格相同，不會破壞原本的內容。
共 599 件、約 1793 萬個方塊、164 種方塊；最高 77 格（巨大樹）。
方位：北（-Z）。結構第 0～2 層是石頭與泥土、第 3 層是地表（與前兩包相同）。

【內容】
瑪利亞之牆與城門
  ・牆高 50 格、厚 9 格，扶壁、牆腳、腰帶線、雨痕，牆頂走道、垛口與 110 門固定砲。
  ・四個城區的城牆向外突出成半圓，每個城區有內門與外門（拱門、吊閘、牆徽、升降架）。
  ・兩條河從羅塞之牆的水門流出，穿過瑪利亞之牆的拱形水門（鐵柵）一直流到邊界。
四城區（共 771 棟有室內的木骨架民宅）
  ・希干希納區 240 棟、瑪利亞北城區 184 棟、瑪利亞東城區 178 棟、昆塔區 169 棟。
  ・與前兩包同樣的房屋：13 種店舖、前店後廚隔間、樓上臥室與起居室、閣樓、後院雜物。
  ・主街貫穿內外城門、城門內廣場、格網街道、路燈、教堂。
希干希納區：845 年被攻破的城門
  ・外門被超大型巨人踢出約 25 格寬、30 格高的大洞，320 塊碎石往城內飛散，砸穿約 130 間房屋的屋頂。
  ・內門（瑪利亞之牆本體）被鎧之巨人撞破，160 塊碎石散落在牆內側。
巨大樹森林（東南）
  ・33 棵樹高 50～70 格的巨大樹：粗樹幹、往外爬的板根、高處才分枝的寬樹冠，
    樹間還有約 160 棵一般大樹，林床是灰壤、苔蘚與蕨類。
鄉間
  ・從羅塞之牆四城門延伸出的四條大道、環狀鄉道、6 個村莊（50 棟農舍）。
    其中 3 個是荒廢村莊（東南東、西南、北北東）：屋頂破洞、窗戶碎裂、石材長苔、蜘蛛網、雜草長進路面。
  ・220 塊田、河流、約 14300 棵樹的森林、草原上的草叢與野花。
  ・瑪利亞之牆外是牆外的世界（草原與森林）。

【一鍵放置（建議，超平坦世界）】
1. 開啟「瑪利亞之牆內延伸.mcpack」，用 Minecraft 匯入，並在世界設定裡啟用（可與另外兩包同時啟用）。
2. 先依說明放好希娜之牆內王都，再放好羅塞之牆內延伸。
3. 這個包的原點 = 羅塞包原點往西、往北各退 192 格（= 希娜包原點各退 448 格，Y 相同）。
   希娜包放在 (0, -64, 0)、羅塞包放在 (-256, -64, -256) 的話，這個包放在 (-448, -64, -448)，
   整片範圍是 X、Z 從 -448 到 1471。
依序執行（每次的座標都要一樣）：
  /execute positioned -448 -64 -448 run function maria/prepare
  （等 3～5 秒讓區塊載入）
  /execute positioned -448 -64 -448 run function maria/build1
  （等 3～5 秒）
  /execute positioned -448 -64 -448 run function maria/build2
  ……依此類推到 build15（每段放 2 列，聊天欄會顯示「第 N/15 段完成」）
  /function maria/cleanup
每一段最多會建立 10 個常駐區塊（tickingarea，每個 192×128），剛好是世界上限。
開始前請先執行 /function sina/cleanup 與 /function rose/cleanup，並確認世界裡沒有其他常駐區塊
（可用 /tickingarea list 查看、/tickingarea remove_all 全部清掉）。
若某一塊沒出現，通常是區塊尚未載入：走近那一區，再用同樣座標執行一次該段 build（重複載入不會壞）。
一般世界：原點 Y 改成當地地面高度減 3，並先整平 1920×1920 的空地（中央 1536×1536 給前兩包）。

【逐件放置（結構方塊或指令）】
結構名稱 maria_261103:tile_x<i>_z<j>，放在 (X+64i, Y, Z+64j)，X、Y、Z 是這個包的原點，i、j 是 0～29。
  i、j 都在 3～26 的是羅塞包的範圍，其中只有羅塞之牆外側有改動的分件存在
  （完整清單就是行為包 functions/maria/build1～build15.mcfunction 裡的載入指令）。
  例：/structure load maria_261103:tile_x0_z0 -448 -64 -448

【注意】
  ・結構裡的空氣會清掉原地的方塊，請放在空地上。
  ・羅塞範圍內的 275 件會覆蓋羅塞包對應的分件，這是正常的（裡面已包含羅塞包牆內的內容）。
    一定要照「希娜 → 羅塞 → 瑪利亞」的順序放。
  ・羅塞包原本牆外的填充森林會被換成瑪利亞之牆內的土地。
  ・只需匯入行為包，不需更換 db 或世界檔。這不是 Java 版 schematic，也不是完整世界。
  ・ID 用 maria_261103 這個新 namespace，不會跟 sina_261103、rose_261103、aot_261102 衝突。
  ・一些店舖與宅邸有箱子、木桶，但裡面是空的。
