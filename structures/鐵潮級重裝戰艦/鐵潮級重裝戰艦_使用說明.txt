鐵潮級重裝戰艦 — Minecraft 基岩版 26.50 建築包

一、作品
依三張參考截圖復刻辨識特徵，並非原作者逐格原版檔案。
寬57 × 深241 × 高68格；結構座標X=57、Y=68、Z=241。
實際非空方塊 96,153 個，33種方塊（包含狀態變體共72項palette含air）。
船首朝北/−Z，船尾朝南/+Z。原點是包圍盒最小X/Y/Z角，不是船中心。
船中心X=28，主甲板本地Y=14，水線本地Y=8，最高桅杆Y=66。
內容：4座三聯主砲、14座雙聯副砲、8座近防砲、五層指揮塔樓、橫翼測距儀、
雙煙囪、救生艇、錨鏈、艙口、甲板雙軌、通風格柵、分層裝甲、寢艙、機艙、餐廳與海圖桌。
砲、引擎、救生艇與臥鋪為靜態造型；不會開火、航行或提供床的睡眠功能。
桶子等原版容器未預填物品。

二、匯入
1. 開啟「鐵潮級重裝戰艦.mcpack」並選Minecraft。
2. 進入世界設定→行為包→啟用「鐵潮級重裝戰艦」。
3. 開啟作弊，建議創造模式。最低宣告版本1.26.50（遊戲顯示26.50）。
   以Mojang官方v1.26.50.4方塊表驗證；不保證舊版相容。

三、整艘放置（建議）
先選好一片長241、寬57格且水深至少9格的空海域。
例如原點選 (0,54,0)，海面水方塊Y=62，船首大致位在(28,62,3)。
以下座標只是範例，請將兩條指令的 0 54 0 一起改為你選好的原點。

第一步：预載完整區域（避免船尾因距離太遠而未載入）
/execute positioned 0 54 0 run function iron_tide/prepare

等區域載入約5秒，確認沒有tickingarea錯誤，再執行：
/execute positioned 0 54 0 run function iron_tide/build

build會依正確偏移載入四件，並移除本包建立的暫時載入區域。
若提示區域尚未載入，重新prepare、等區域完成載入再build。
若世界已達常載區域上限，需騰出一個名額；本包不會刪除其他常載區域。
取消預載可執行 /function iron_tide/cleanup 。
不要在船中心直接 /function iron_tide/build；那會以你所在位置作包圍盒原點。

四、手動分件（同一包，不需另外下載）
依序使用以下完整ID；每件都寬57、高68，最後一件深49，其餘深64。
原點範例仍為(0,54,0)：
/structure load iron_tide_260920:section_01 0 54 0
/structure load iron_tide_260920:section_02 0 54 64
/structure load iron_tide_260920:section_03 0 54 128
/structure load iron_tide_260920:section_04 0 54 192
通用偏移：01=(0,0,0)、02=(0,0,64)、03=(0,0,128)、04=(0,0,192)。
四件不旋轉、不鏡像、完整性100%；務必保持同一原點與同一朝向。
可 /give @s structure_block，放置後切到「載入」，輸入完整ID。
若用結構方塊介面，應依結構方塊位置設定偏移，使載入角對準上述原點。

五、探索
外側甲板樓梯在本地X12..13 / X43..44，Z94..100。
船艙入口梯井在本地X28、Z93與190；中央塔樓梯井X28..29、Z126。
下層艙室中央走廊約X26..30、Y7，上一層Y11。
範例原點可用 /tp @s 28 69 93 到前部甲板梯井附近。

六、覆蓋規則與限制
建築會在57×68×241範圍放置方塊；上方空氣和艙內空氣會清空原有方塊。
水線以下、船殼外部的空格使用-1保留原海水；船殼內使用air以形成乾燥艙室。
必須選空海域；原有地形或建築落在船殼、甲板與上方空間仍會被覆蓋。
本包不是世界存檔，不含db，不需替換世界資料。
截圖的材質包、光影與海面效果不含在本包；原版顯示效果與預覽示意色不同。
曲面船殼以逐格退縮近似；船首、船尾、水下與室內部分依風格推測補完。

中心通道與梯井、船殼水線以下空間隔離、ZIP CRC、manifest/UUID與所有包內路径。
