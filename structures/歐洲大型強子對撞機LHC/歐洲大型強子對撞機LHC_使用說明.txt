歐洲大型強子對撞機 LHC — Minecraft 基岩版結構行為包（v1.0.1）

【簡介】
CERN 大型強子對撞機（LHC）縮小版，地下環形隧道加上四大偵測器，裡面的紅石都會真的動：
- 雙束流環：環形隧道裡的藍色偶極磁鐵內藏兩條「中繼器＋紅石燈」鏈，下層束流 1 順時針、上層束流 2 逆時針，
  透過磁鐵側面的淺藍玻璃可以看到一串亮燈（束流團）在環裡跑，一圈約 40 秒。
- 注入鏈：在 CCC 控制中心按「注入」鈕，光點會沿著真實的加速器順序跑：
  CCC 計時線 → 紅石下降螺旋 → Linac4 直線加速器（銅色）→ PS Booster（綠）→ PS 質子同步加速器（深綠，位於環心）
  → SPS 超級質子同步加速器（紅）→ 分岔成 TI2（往西）與 TI8（往東）→ 同時注入 LHC 兩條束流。
- 兩批注入：按一次按鈕會自動送出兩批束流團，第二批由 CCC 地板展示櫃裡的「計時蛇形線」延遲剛好半圈（20 秒）。
  這樣算出來的相遇點正好落在四個實驗：ATLAS 與 CMS 由同批束流相撞，ALICE 與 LHCb 由不同批相撞。
- 碰撞觸發：每個偵測器中心有一組符合閘（中繼器、紅石火把、減法比較器 = 束流1 AND 束流2）。
  兩道束流同時經過時，偵測器 1/4 剖切面上的「粒子徑跡」燈會從中心往外一路亮出去。
  注入後每個實驗大約每 20 秒碰撞一次，會一直持續。
- 束流傾卸：CCC 的「傾卸」拉桿往 P6 送訊號，鎖住環上的減法比較器，束流在一圈（40 秒）內被吸收。
  拉回拉桿後環是空的，可以重新注入。傾卸點旁有石墨吸收體洞室。
- P4 RF 加速腔：銅色腔體段，束流經過時腔體燈會跟著閃。P3/P7 有黑鐵色準直器。

【四大實驗（約 1 格 = 1 公尺）】
- ATLAS（P1，南）：46 長 × 25 高，8 個環形線圈、銅色液氬量能器、深色鐵磚量能器、兩端 μ 子大輪。
- CMS（P5，北）：21 長 × 15 高，十二邊形紅色回軛、金色強子量能器、銀色超導螺線管。
- ALICE（P2，西）：紅色八角 L3 磁鐵與紅色大門、白色 TPC、往北延伸的 μ 子臂（吸收體、雙極磁鐵、追蹤站、鐵牆）。
- LHCb（P8，東）：單臂前向譜儀，VELO、RICH、紅黑雙極磁鐵、追蹤站、量能器、μ 子站；徑跡只往前方噴。
每座洞室都有：吊車、參觀走廊（在剖切那一側的牆邊）、玻璃牆計數室、通到地面的螺旋樓梯井與地面小屋、
直通地面實驗廳的大豎井（從地面廳可往下看見偵測器）。

【地表】
CCC 控制中心（東北，玻璃帷幕，四個控制島、北牆大螢幕、計時線展示櫃、兩座玻璃紅石螺旋井）、
四座實驗地面廳（含天車）、科學與創新之球（木造球體）、沿地下環線鋪的環形道路、十字道路、停車場、樹木。

【尺寸】
寬 256 × 深 256 × 高 72 格（X=256、Y=72、Z=256），切成 4×4 共 16 個分件（每件 64×72×64）。
共約 247 萬個方塊（地下岩層為實心填滿）、126 種方塊狀態、2,500 多個紅石元件。
高度配置（相對結構原點）：y0 基岩、y39 草地（地表）、y40 起為地面建築；隧道地板 y12、束流 1 在 y15、束流 2 在 y17。
方位：北 = -Z。環心在原點 +128,+128；ATLAS 在南（+128,+228），CMS 北（+128,+28），ALICE 西（+28,+128），LHCb 東（+228,+128）。

【匯入與啟用】
1. 開啟（雙擊）歐洲大型強子對撞機LHC.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立或編輯世界 → 行為包 → 啟用「歐洲大型強子對撞機LHC」。世界要開啟「作弊」。
3. 也可用建築放置台放置（建築放置台附加包啟用時，選單會自動列出這座建築）。

【一鍵放置（建議）】
選一塊平地，把結構原點 Y 設成「地面高度 − 40」，草地就會跟地面切齊。例如地面在 Y=64，原點用 0 24 0：
  /execute positioned 0 24 0 run function lhc/prepare
  （等 5～10 秒讓區塊載入）
  /execute positioned 0 24 0 run function lhc/build
prepare 會建立 4 個常駐區塊（tickingarea，各約 85 區塊），把整座 256×256 都保持載入；build 依序載入 16 個分件。
若某一塊沒出現，通常是區塊還沒載入：等幾秒再執行一次 build（重複載入不會壞）。
※ 常駐區塊請先保留：紅石只在已載入的區塊運作，移除後玩家走遠，束流就會停在沒載入的地方（回來後會接著跑）。
  不需要時再 /function lhc/cleanup 移除；之後想恢復運轉可再執行 /execute positioned 0 24 0 run function lhc/keepalive。
※ 地底 0～39 層會被整片換成岩層與隧道（會蓋掉原本的礦洞與礦物），地面以上 32 格的空氣也會清空。

【參觀傳送（同樣加 /execute positioned <原點> run …）】
  function lhc/view    → 南方高空看全景
  function lhc/ccc     → CCC 控制中心內（面向注入鈕與傾卸桿）
  function lhc/atlas、lhc/cms、lhc/alice、lhc/lhcb → 各洞室的參觀走廊，面向碰撞點
  function lhc/tunnel  → 環形隧道 P4 RF 加速腔旁的走道

【操作】
- 注入：CCC 西側控制台中間的石頭按鈕（原點 +158, +42, +52）。按一次 = 兩批束流團。
  約 21 秒後束流進入 LHC，再過 18～40 秒四個實驗依序開始碰撞。可以多按幾次增加束流團（多出來的不一定剛好在實驗點相撞）。
- 傾卸：CCC 北側控制台中間的拉桿（原點 +172, +42, +43）。拉下 = 傾卸；等 40 秒後拉回，就可重新注入。
- 好看的位置：ATLAS／CMS 參觀走廊看徑跡噴發；CCC 地板展示櫃看計時線光點蛇行；
  CCC 兩座玻璃井看紅石粉螺旋下降；環形隧道走道看束流光點從磁鐵玻璃窗經過。

【紅石設計重點（給想研究的人）】
- 環路：粗網格走法每步加倍，所以中繼器一定在直線格、燈在轉角格；兩條束流上下疊放同一路徑，每格延遲完全一樣（一圈 400 紅石刻）。
- 碰撞：束流1 燈 → 側接中繼器 → 鐵塊 → 火把（反相）→ 鐵塊 → 中繼器打進比較器側邊；束流2 燈 → 中繼器打進比較器後端；
  比較器減法模式輸出 = B − NOT(A) = A AND B。
- 傾卸：環上那一格用減法比較器取代中繼器，側邊有 15 時輸出 0，不論束流在哪都不會卡住（用中繼器側鎖會卡在亮的狀態）。
- 地面到地下用紅石粉螺旋（每圈一個中繼器補強度），TI8 最後用兩階紅石粉爬到束流 2 高度；TI2 對應放平的紅石粉，兩邊延遲相同。

【已知簡化】
- 真實 LHC 周長 27 公里，這裡縮成邊長約 200 格的圓角正方形；四個實驗排在四邊中點（真實 ALICE、LHCb 離 ATLAS 只有 1/8 圈）。
- 兩條束流在真實磁鐵裡是左右並排，這裡改成上下疊放，才能讓兩條路徑延遲完全相同。
- 偵測器形狀依公開外觀簡化成方塊層次，並做 1/4 剖切展示內部；SPS、PS 等加速器縮成小型圓角方環，束流只跑 3/4 圈就引出。
- 地面建築外觀為示意，非實際建築。

【注意】
- 不要在結構方塊按「儲存」覆蓋同名結構；只需匯入行為包，不需更換 db 或世界檔。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。

方塊名稱與 state 依 Mojang bedrock-samples v1.26.60.5 官方方塊表檢查；行為包宣告最低版本 1.26.60。

紅石以自寫模擬器（紅石刻粒度，依 Java/基岩共通規則）在「含全部建築方塊」的整座結構上測試：

  CMS 第 398 刻、ALICE 與 LHCb 第 498 刻、ATLAS 第 598 刻起，每個實驗每 200 刻（20 秒）碰撞一次；
  傾卸後 450 刻內環上 0 個元件亮，拉回後回到靜止狀態，再注入仍正常碰撞。
模擬器有簡化（沒有模擬火把燒毀、更新順序等細節）。格式與模擬驗證通過，尚未在 Minecraft 客戶端內實際載入測試。
