霜翎級輕巡洋艦 — Minecraft 基岩版 26.50 建築包

一、作品
依三張參考截圖復刻辨識特徵（白/灰/橘配色現代科幻戰艦），並非原作者逐格檔案；依要求做成較小尺寸、高細節。
寬27 × 深120 × 高38格；結構座標X=27、Y=38、Z=120。
實際非空方塊 20,959 個，37種方塊（含狀態變體共85項palette含air）。
船首朝北/−Z，船尾朝南/+Z。原點是包圍盒最小X/Y/Z角，不是船中心。
船中心線X=13，主甲板本地Y=10，艏樓甲板Y=11，水線本地Y=5，桅頂Y=36。
內容：3座三聯主砲（前二後一、B砲塔超射）、8座白頂雙聯副砲舷台、6座近防砲、
三層退縮艦橋與外伸翼台、桅杆橫向雷達、煙囪、後指揮塔、4艘救生艇、錨鏈絞盤、
甲板雙軌與艙口通風筒、橘色船緣與縫隙燈、下層寢艙/工作間/機艙/儲藏艙、艦橋操作台與海圖桌。
砲、引擎、救生艇與臥鋪為靜態造型；桶子等容器未預填物品。

二、匯入
1. 開啟「霜翎級輕巡洋艦.mcpack」並選Minecraft。
2. 進入世界設定→行為包→啟用「霜翎級輕巡洋艦」。
3. 開啟作弊，建議創造模式。最低宣告版本1.26.50（遊戲顯示26.50）。
   以Mojang官方v1.26.50.4方塊表驗證；不保證舊版相容。

三、整艘放置（建議）
選一片長120、寬27格、水深至少6格的空海域。
例如原點選 (0,57,0)，海面水方塊Y=62，船首尖端大致在(13,62,2)。
以下座標只是範例，請將兩條指令的 0 57 0 一起改為你選好的原點。

第一步：預載完整區域
/execute positioned 0 57 0 run function frost_plume/prepare

等區域載入約5秒，再執行：
/execute positioned 0 57 0 run function frost_plume/build

build會依偏移載入兩件並移除暫時載入區域。若提示區域尚未載入，重新prepare後再build。
取消預載可執行 /function frost_plume/cleanup 。
不要站在船中心直接 /function frost_plume/build；那會以你所在位置作包圍盒原點。

四、手動分件（同一包）
兩件都寬27、高38、深60，原點範例仍為(0,57,0)：
/structure load frost_plume_260920:bow 0 57 0
/structure load frost_plume_260920:stern 0 57 60
通用偏移：bow=(0,0,0)、stern=(0,0,60)。不旋轉、不鏡像、完整性100%，保持同一原點與朝向。
也可 /give @s structure_block，放置後切到「載入」，輸入完整ID。

五、探索
下層艙室梯井：艏樓後方本地(13,Y,38)與艉甲板(13,Y,90)的艙口，往下到Y6走廊。
艙面建築門：兩舷X5/X21、Z66，以及前後Z40/Z88中央。
艦橋內部梯井在(13,Y,56)，從艙面建築Y11一路到第三層Y24。
外側甲板樓梯在X6..7 / X19..20，Z89..93 通往艙面建築屋頂。
範例原點可用 /tp @s 13 69 39 到艏樓後緣艙口附近。

六、覆蓋規則與限制
建築會在27×38×120範圍放置方塊；上方空氣和艙內空氣會清空原有方塊。
水線以下、船殼外部的空格使用-1保留原海水；船殼內使用air形成乾燥艙室。
必須選空海域；原有地形或建築落在船殼、甲板與上方空間仍會被覆蓋。
本包不是世界存檔，不含db。截圖的材質包、光影與海面效果不含在本包。
曲面船殼以逐格退縮近似；船首、船尾、水下與室內依風格推測補完；
副砲數量、艦橋層數與甲板設備依可辨識特徵安排，非逐格復刻。

七、驗證狀態
格式驗證通過，尚未在遊戲內實測。
已驗證官方方塊名稱/state及NBT型別、兩件索引長度、分件重新拼接等於完整模型、
中央走廊與兩座梯井連通、水線以下空間隔離、ZIP CRC、manifest/UUID與包內路徑。
兩張PNG依最終方塊陣列與states繪製，非遊戲截圖；已人工開啟檢查。
