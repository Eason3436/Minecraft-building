石環鬥獸場 — Minecraft 基岩版建築包

尺寸：寬128 × 深128 × 高52格；NBT X=128、Y=52、Z=128。
主體為橢圓形：長軸（東西）約 120 格、短軸（南北）約 104 格，外牆頂高 43 格，旗桿至 50 格。
整體為同一模型，因單一結構 64 格限制，切成 4 件 64×52×64，放在同一個行為包。
原點為最小 X/Y/Z 角，正門朝北（−Z）。
共 102,154 個方塊、62 種方塊、光源約 1,460 個。

一、建築內容（依參考圖復刻）
・外立面四層：一層高拱窗（灰玻璃）、二三層拱口＋深色木欄杆陽台、四層閣樓方窗；
  每開間以雙層外凸壁柱分隔，壁柱每層有柱頭托石，每層一道淺色簷口。
・頂部：白色齒狀女兒牆與托石簷口，外緣一圈細旗桿。
・屋頂即上段看台：10 階橡木與白色交錯的同心座位帶，12 條深色放射走道，內緣深色欄杆與燈柱。
・正門（北）：退縮階梯尖拱、鑰石、雙扇深色木門、門內吊燈；東、南、西三向為大拱門。
・正門兩側與東西門兩側壁柱上有紅白 X 形旗飾。
・景觀：石板環形廣場、正門大道、燈柱、灌木與花帶、四角的橡樹與白樺。

二、室內
・競技場：沙地、中央徽紋、跑道圈、乾草與標靶；四周擋牆與矮牆。
・下段看台：6 排深色雲杉座位、8 條深色橡木走道（座位本身就是階梯，可直接走上去）。
・內迴廊兩層：面向場內的欄杆拱口、拱頂吊燈、長椅、花盆與陶罐。
・舞台（南側）：木地板舞台、兩層石造立面（石英柱、門、窗、陽台、三角山牆）、左右雙梯、紅色帷幕、道具；
  立面後方為後台（箱子、木桶、燈），經南側隧道與外環相通。
・外環迴廊四層：一層商攤（木桶、箱子、乾草、燻爐、工作台、長椅）；二層長椅迴廊（對外開敞）；
  三層兵器與倉儲（鐵砧、木桶）；四層閣樓倉庫。每層沿中線吊燈。
・動線：北正門隧道直通競技場；外環 → 二、三層有 8 條放射通道通往內迴廊；
  外環西端樓梯（一→二層、三→四層）、東端樓梯（二→三層、四層→屋頂看台）。
・封閉的看台下方空間放了隱形光源方塊，防止生怪。

三、匯入
1. 雙擊「石環鬥獸場.mcpack」匯入 Minecraft。
2. 世界設定 → 行為包 → 啟用「石環鬥獸場」。開啟作弊，建議創造模式。
3. 依 Mojang 官方 1.26.50 方塊表製作，宣告最低引擎 1.26.50；不保證更舊版本可用。

四、一條指令慢速放置（推薦）
/function colosseum/start
固定放在主世界原點 (0,60,0)，與你站的位置無關；佔用 X0..127、Y60..111、Z0..127，會覆蓋該範圍。
自動預載一個區域（需 1 個 tickingarea 名額），載入完成後 10 秒開始，4 件各 60 秒逐層放置、間隔 10 秒，
約 5 分鐘完成並自動清理預載區。期間保持世界開啟；重複 start 不會疊加。
中止後續分件：/function colosseum/stop（進行中的那件仍會完成，70 秒後清理預載區）。

五、自選位置立即放置
1. 指定你要的原點（建築最小角），執行：
   /execute positioned <x> <y> <z> run function colosseum/prepare
2. 等 5～10 秒區塊載入後：
   /execute positioned <x> <y> <z> run function colosseum/build
3. 完成後：/function colosseum/cleanup
三條指令的 <x> <y> <z> 必須相同，且整個 52 格高度要在世界高度內。<y> 建議設為地面高度（結構 Y0 是草地層）。

六、手動分件或結構方塊
/give @s structure_block → 放下後切換「載入」模式，輸入完整 ID，例如 stone_colosseum_260923:tile_x0_z0。
tile_xI_zJ 的偏移為 (I×64, 0, J×64)，I、J = 0..1；不旋轉、不鏡像、完整性 100。
以原點 (0,60,0) 為例的 4 條指令：
/structure load stone_colosseum_260923:tile_x0_z0 0 60 0
/structure load stone_colosseum_260923:tile_x0_z1 0 60 64
/structure load stone_colosseum_260923:tile_x1_z0 64 60 0
/structure load stone_colosseum_260923:tile_x1_z1 64 60 64

背面、全部室內與舞台細節為依風格推測補完。附圖依最終方塊資料繪製，非遊戲截圖。
