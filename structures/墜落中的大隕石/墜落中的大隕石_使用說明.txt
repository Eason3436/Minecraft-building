墜落中的大隕石 — Minecraft 基岩版結構行為包（v1.0.0）

【簡介】
一顆正在穿過大氣層、往下墜落的大隕石，設計成直接放在天上（浮空結構，不需要地面）。
岩體直徑約 32 格，朝東南方斜斜往下衝；前方受熱面發紅發亮，外面罩著一層半透明的電漿光罩，
表面布滿發光的熔岩裂縫，邊緣甩出一條條火舌；後方拖著約 100 格長的尾跡，
由白熱 → 黃 → 橙 → 紅 → 深灰濃煙 → 淺灰 → 白煙漸層，越往後越鬆散、碎成一團團煙雲，
周圍還有 22 塊飛散的碎石（部分內部發光）與 260 顆火星。
岩體內部可以進去：側面有一條隧道通往紫水晶晶洞，中央立著一根隕鐵核心柱。
附圖：墜落中的大隕石_整體渲染.png、墜落中的大隕石_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。

【尺寸】
寬 96 × 深 96 × 高 112 格（X=96、Y=112、Z=96），在 100×100 以內；切成 2×2 共 4 個分件（最大 64×64）。
共 44,822 個方塊、44 種方塊。
方位：隕石往東南方（+X、+Z）並往下墜落；尾跡往西北上方延伸。
以結構原點為 (0,0,0)：岩體中心約在 (64, 24, 64)，最低點約 Y+3，煙尾最高到 Y+111。

【匯入與啟用】
1. 開啟（雙擊）墜落中的大隕石.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立或編輯世界 → 行為包 → 啟用「墜落中的大隕石」。
3. 世界要開啟「作弊」（指令）。

【一鍵放置（建議）】
在主世界執行（原點 0 150 0 為例，放好後整顆在 Y=153～261 的天空中；建築上限 320，不會超出）：
  /execute positioned 0 150 0 run function meteor/prepare
  （等 3～5 秒讓區塊載入）
  /execute positioned 0 150 0 run function meteor/build
  /function meteor/cleanup
參觀：
  /execute positioned 0 150 0 run function meteor/view     → 傳送到側面看全景（約 -30 190 125）
  /execute positioned 0 150 0 run function meteor/inside   → 傳送進晶洞（約 60 173 66）
prepare 建立 1 個常駐區塊（tickingarea），build 依序載入 4 個分件，cleanup 移除常駐區塊。
若某一塊沒出現，通常是區塊尚未載入：站近一點再執行一次 build（重複載入不會壞）。
※ 想換位置，把 0 150 0 換成你要的座標即可；Y 建議 ≥ 70，確保整顆在空中、而且頂端不超過 320。

【逐件放置（結構方塊或指令）】
取得結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入結構名稱（旋轉 0°、無鏡像、完整性 100%）。
自訂原點 (X, Y, Z) 時：分件 tile_x<i>_z<j> 放在 (X+64i, Y, Z+64j)。以原點 (0, 150, 0) 為例：
  /structure load meteor_261103:tile_x0_z0 0 150 0
  /structure load meteor_261103:tile_x0_z1 0 150 64
  /structure load meteor_261103:tile_x1_z0 64 150 0
  /structure load meteor_261103:tile_x1_z1 64 150 64

【看點】
- 受熱面：朝墜落方向的那一面是岩漿塊、哭泣黑曜石、黑曜石、蕈光、地獄岩混成的熔殼，外層兩格都在發光。
- 電漿罩：受熱面外 2～4 格罩著一層白／黃／橙色染色玻璃，越正前方越白熱。
- 熔岩裂縫：表面一圈圈發光的裂縫網路，凹槽底部是蕈光、岩漿塊、赭黃蛙光燈，向上的裂縫裡有 213 格真的熔岩。
- 熱蝕凹坑：岩體表面的小凹洞（隕石穿過大氣層時被燒出的「指紋坑」）。
- 火舌：岩體側緣往後甩出的火焰條紋。
- 尾跡：中心較熱、外圈較冷，外緣一層是半透明染色玻璃，看起來會透光；後段的煙雲有少量蜘蛛網當作稀薄的煙絲。
- 內部（從西南側隧道進去，入口約在原點 +51, +23, +74）：
  隧道約 2 格寬、3 格高，牆上每 4 格一盞蕈光；盡頭是直徑約 15 格的紫水晶晶洞，
  洞壁是方解石＋紫水晶塊（含紫晶母岩，會自己長出晶芽），珍珠蛙光燈照明，地上長著紫水晶簇；
  中央是一根隕鐵核心柱（粗鐵塊、鐵塊，頂端一塊遠古遺骸）。岩體深處也有粗鐵塊與遠古遺骸的礦脈。

【已知簡化】
- 火焰與煙霧用方塊表現，是靜止的；尾跡裡面是實心的（混凝土、羊毛、玻璃），不是可以穿過的煙。
- 為了避免起火，沒有放真正的火焰方塊；羊毛煙雲離熔岩至少 20 格。
- 熔岩只放在四周和下方都被方塊包住的凹槽裡，放置後不會流出來。

【注意】
- 結構外部的空氣存成「結構空位」，放置時不會清除原地方塊；只有晶洞與隧道裡的空氣會清除。請預留 96 × 96 × 112 的空間。
- 隧道入口外面就是天空，走出去會掉下去；建議用 meteor/inside 直接傳送進去，或開創造模式飛行。
- 晚上看效果最好：岩漿塊、蕈光、蛙光燈、螢石都會發光。
- 不要在結構方塊按「儲存」覆蓋同名結構；只需匯入行為包，不需更換 db 或世界檔。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。
