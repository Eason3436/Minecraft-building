環山中世紀古城 — Minecraft 基岩版結構行為包（v1.1.1）

【簡介】
一座照現實歐洲中世紀城鎮（德國、法國一帶）樣貌建造的城市，四周被一圈雪頂環形山脈包圍。
盆地內是起伏的丘陵與草坡，三條礦車鐵路順著地形蜿蜒，互相立體交叉，並各自鑿隧道穿過山脈通往外界。
附圖：環山中世紀古城_整體渲染.png、環山中世紀古城_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。
可用建築放置台放置。

【尺寸】
寬 256 × 深 256 × 高 96 格（X=256、Y=96、Z=256），切成 4×4 共 16 個分件（每件 64×96×64）。
設計給「超平坦」世界：結構最底層＝基岩層（Y=-64），山外四角的草地高度＝超平坦地面（Y=-61），接縫看不出來。
盆地（城市）地面比外面高 5 格（Y=-56），城外丘陵最高再高出約 30 格。北方＝-Z。
約 205 萬個方塊（大多是山體石頭），300 多種方塊狀態。

【場景內容】
一、環形山脈與丘陵：主稜高低起伏（約 50～90 格），有多座山峰與伸向盆地的山脊支稜，峰頂積雪、最高處露出方解石；
    山壁有層狀岩層（安山岩、凝灰岩、閃長岩），緩坡上是草地、粗泥與灰壤，坡上散布雲杉林。
    山腳到城牆之間是一圈起伏的丘陵與谷地，風車、田地、農舍都順著丘陵高低擺放。
    西北山中有一個半圓形的冰斗山谷，30 格高的瀑布從崖頂落下成潭，小河往南流過城西，注入西南的湖泊。
    山外四角也是緩緩起伏的混合林與草地。
二、城牆：圓形石砌城牆（雉堞、箭孔、牆頂步道），7 座圓塔（黑瓦圓錐頂），西門、東門、南門三座門樓（吊閘）。
三、城堡（城北土丘上）：雙層幕牆、四角圓塔、南面門樓與坡道、30 格高的主塔（Bergfried，內有梯子可登頂）、
    大廳（Palas：長桌、王座、壁爐、吊燈、掛毯）、馬廄、水井。
四、哥德式大教堂（廣場東側）：西立面雙塔＋八角尖塔（塔頂掛鐘）、玫瑰窗、尖拱大門、彩色玻璃側窗與高側窗、
    飛扶壁、十字形翼部與交叉點小尖塔、半圓後殿；室內黑白棋盤地磚、長椅、紅地毯、詩班席、祭壇、吊燈。
五、市政廳（廣場西側）：石造，一樓拱廊市場廳，二樓議事廳（長桌、書架、講台），階梯山牆，鐘樓（鐘面＋鐘）。
六、市集廣場：石板拼花、中央噴泉、8 座彩色帆布攤位、燈柱。
七、木筋屋街區：33 棟自動排列在街巷兩側的住宅與店鋪，一樓石砌、上層白／米／赭／粉色灰泥牆配深色木架與斜撐，
    上層出挑到街上（下方木托架）、陡坡屋頂（黑石板瓦／紅瓦／深色木瓦）、煙囪（部分冒煙）、百葉窗與花箱；
    約 2 成是石造商人屋（階梯山牆）。一樓依店種擺設：麵包店、鐵匠、酒館、雜貨店、織布坊、藥房、桶匠、住家；
    樓上是臥室（床、箱子）或客廳書房，各層有吊燈與梯子。
八、城外：風車（東北丘陵上）、水車磨坊（西側河邊）、農舍、麥田／紅蘿蔔／馬鈴薯／甜菜田（中間有灌溉水道）、
    圍籬牧場、果樹園、野花草地、樹林。

【三條鐵路（交織方式）】
三條線都依地形蜿蜒：遇丘陵就鑿隧道或挖路塹（兩側階梯狀邊坡），遇低處就築草皮路堤，
過河、湖、谷地或別的鐵路時走石拱橋（橋墩每 7 格、橋側矮牆、橋燈）。坡度最多每格升降 1 格，只在直線段爬坡。
右側附的俯視鐵路圖可看出走向（深色段是隧道）。
 ・環線（紅）：彎曲地繞著城市一圈，共 612 格，封閉迴圈，礦車可一直繞圈；軌面高度隨地形在 Y=-55～-48 之間起伏，
   東側穿過兩段丘陵隧道。南側有「南環站」（z=199、x133～149，月台＋木雨棚）。
 ・B 線（橘，東西向）：376 格。從西邊山外隧道進來，沿湖南岸繞過，爬上石拱高架橋，
   在城南的「中央車站」（z=180、x110～146，軌面 Y=-44）停靠：高架橋下是石造候車大廳（南門大道從大廳拱門穿過），
   兩側樓梯上到橋面月台（雨棚、長椅、燈）。之後向東北彎行，跨過環線與 C 線，再穿山而出。
 ・C 線（藍，南北向）：322 格。從北邊山外隧道蜿蜒下來，在城東設「東門站」（x=186、z134～154，雙月台、雨棚、站房）；
   一路壓低高度，兩度從環線下方穿過、也從 B 線高架橋下穿過，南段再鑽進山中隧道。
 ・三條線在交叉處都是上下錯開（最少相差 5 格），沒有平交道。
 ・B 線與 C 線兩端都直通結構邊緣（Y=-60 的軌道），可以自己往外接延長線。
 ・動力軌：直線段每 9 格一根、所有坡道都是動力軌，底下用紅石方塊供電（不用任何紅石線路）。
 ・隧道內壁為石磚襯砌，每 12 格一盞燈；隧道口有石拱門面。

【匯入與啟用】
1. 雙擊「環山中世紀古城.mcpack」匯入 Minecraft（手機用「分享／開啟方式」選 Minecraft）。
2. 建立新世界：世界類型選「超平坦」，建議創造模式、開啟作弊。在「行為包」啟用「環山中世紀古城」。

【一鍵放置（建議）】
三行的座標要相同；座標＝結構西北角，Y 一定要 -64：
  /execute positioned 0 -64 0 run function medtown/prepare
  （等 5～10 秒讓區塊載入）
  /execute positioned 0 -64 0 run function medtown/build
  /execute positioned 0 -64 0 run function medtown/life      ← 選用：放礦車、村民、馬、牛羊（只執行一次）
  /function medtown/cleanup
prepare 建立 4 個常駐區塊（tickingarea），build 依序載入 16 個分件，cleanup 移除常駐區塊。
若有一塊沒出現，多半是區塊尚未載入：飛到那一區再執行一次 build（重複載入不會壞）。
life 會在中央車站、東門站、南環站各放 2 台礦車，並在廣場放 6 位村民、城堡馬廄放 2 匹馬、牧場放牛羊。
※ 世界中常駐區塊上限是 10 個，若已用掉 7 個以上請先移除舊的。

【快速傳送（在放置點執行，同樣要加 execute positioned 0 -64 0 run）】
  function medtown/view       從南方山外高處俯瞰全城
  function medtown/square     市集廣場
  function medtown/station    中央車站月台
  function medtown/castle     城堡門樓前
  function medtown/cathedral  大教堂正門
  function medtown/waterfall  瀑布

【逐件放置（結構方塊或指令）】
/give @s structure_block → 放下 → 模式切「載入」→ 輸入結構名稱（旋轉 0°、無鏡像、完整性 100%）。
分件 medtown_261109:tile_x<i>_z<j>（i、j = 0～3）放在 (X+64i, -64, Z+64j)。例：
  /structure load medtown_261109:tile_x0_z0 0 -64 0
  /structure load medtown_261109:tile_x2_z1 128 -64 64
  /structure load medtown_261109:tile_x3_z3 192 -64 192

【搭乘礦車】
放上礦車後坐上去，按前進鍵推一下即可出發；環線是封閉迴圈，B、C 線開到結構邊緣後軌道就結束（礦車會停在端點）。

【注意】
・結構的空氣會覆蓋原地形（整個 256×256×96 範圍會被清空再放置），請放在空地。
・瀑布與河、湖是靜止水源方塊；瀑布頂端水會沿崖壁往下流，屬正常現象。
・作物、動力軌、紅石方塊都已設好狀態；門、床、玻璃板、柵欄連接已預先計算。
・測試狀態：結構格式、尺寸、方塊名稱與狀態已用 Mojang 官方方塊表（v1.26.60）驗證，三條鐵路逐格檢查軌道連續、
  上方淨空（共 1310 格，0 缺軌、0 阻擋）；尚未在遊戲內實測。
