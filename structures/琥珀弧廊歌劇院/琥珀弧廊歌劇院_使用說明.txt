琥珀弧廊歌劇院 — Minecraft 基岩版建築包

尺寸：寬128 × 深128 × 高80格；NBT X=128、Y=80、Z=128。
整體為同一模型，因單一結構 64 格限制，切成 4 件 64×80×64，放在同一個行為包。
原點為最小 X/Y/Z 角，正面（中央門樓與廣場）朝北（−Z）。
共 171,551 個方塊、111 種方塊、光源約 1,049 個。

一、建築內容（依參考圖復刻）
・弧形兩層正立面：一層連續拱廊（粗面石、鑰石、拱內吊燈、壁柱燈座），
  二層每開間成對白柱＋金色柱頭、大拱窗、陽台門；上下各一圈露台欄杆。
・屋頂露台一圈台座與暗色雕像；後退一圈的鼓座（壁柱、方窗、簷口）與綠銅緩頂、頂部採光亭。
・中央門樓：四根巨柱、半圓壁龕＋白藍棋盤藻井半穹頂、大拱窗、門廊（棋盤地、柱列、陽台），
  頂部四馬戰車與人像；兩側壁龕雕像、側面分層窗與粗面石。
・後方舞台塔：頂部一圈柱廊、1:2 人字瓦頂、前後三角山牆（浮雕、圓窗）、山尖與角部雕像。
・兩側入口亭：車道拱門、屋頂平台、各一座 15 階戶外大樓梯直通二層露台。
・景觀：前廣場、兩座噴泉、環繞燈柱、花帶、黃色道路、綠籬、樹、後方卸貨場。

二、室內
・一層：黑白棋盤門廳（售票台、柱列、吊燈、紅毯）、環形前廳（大理石環紋地坪、柱環、吊燈、長椅、盆栽）、
  兩翼衣帽間、西翼咖啡吧（酒桶吧台、桌椅、蛋糕蠟燭）、東翼節目書店（書架、講台）、左右大理石大樓梯。
・觀眾廳：斜坡池座（紅椅、走道紅毯）、樂池（譜架、指揮台、唱片機、鐘）、五層包廂（金色欄板、隔間、吊燈）、
  皇家包廂（金冠紅幔）、金色台口、紅色大幕、彩繪穹形天花（天空、金肋、玫瑰心）、多層巨型水晶吊燈。
・二層：雙柱大前廳（拼花木地板、鏡牆、自助餐台、沙發、吊燈）、西翼畫廊（金框畫作）、東翼音樂沙龍（三角鋼琴、書牆、唱片機）。
・鼓座層：環形迴廊（長椅、胸像台座、書架、吊燈），可進入頂層包廂。
・舞台與後台：天幕彩繪、城堡布景、側片、布景樹、吊桿與燈、兩層天橋與梯子、天花格柵、
  後台三層化妝間（鏡子、化妝桌、服裝架、箱子）、後門卸貨口。
・動線：一層→二層（兩翼大樓梯）→鼓座層（兩翼第二段樓梯）；包廂經前廳門與觀眾廳側梯進入。

三、匯入
1. 雙擊「琥珀弧廊歌劇院.mcpack」匯入 Minecraft。
2. 世界設定 → 行為包 → 啟用「琥珀弧廊歌劇院」。開啟作弊，建議創造模式。
3. 依 Mojang 官方 1.26.50 方塊表製作，宣告最低引擎 1.26.50；不保證更舊版本可用。

四、一條指令慢速放置（推薦）
/function amber_opera/start
固定放在主世界原點 (0,60,0)，與你站的位置無關；佔用 X0..127、Y60..139、Z0..127，會覆蓋該範圍。
自動預載一個區域（需 1 個 tickingarea 名額），載入完成後 10 秒開始，4 件各 60 秒逐層放置、間隔 10 秒，
約 5 分鐘完成並自動清理預載區。期間保持世界開啟；重複 start 不會疊加。
中止後續分件：/function amber_opera/stop（進行中的那件仍會完成，70 秒後清理預載區）。

五、自選位置立即放置
1. 站到或指定你要的原點（建築最小角），執行：
   /execute positioned <x> <y> <z> run function amber_opera/prepare
2. 等 5～10 秒區塊載入後：
   /execute positioned <x> <y> <z> run function amber_opera/build
3. 完成後：/function amber_opera/cleanup
三條指令的 <x> <y> <z> 必須相同，且整個 80 格高度要在世界高度內。

六、手動分件或結構方塊
/give @s structure_block → 放下後切換「載入」模式，輸入完整 ID，例如 amber_opera_260923:tile_x0_z0。
tile_xI_zJ 的偏移為 (I×64, 0, J×64)，I、J = 0..1；不旋轉、不鏡像、完整性 100。
以原點 (0,60,0) 為例的 4 條指令：
/structure load amber_opera_260923:tile_x0_z0 0 60 0
/structure load amber_opera_260923:tile_x0_z1 0 60 64
/structure load amber_opera_260923:tile_x1_z0 64 60 0
/structure load amber_opera_260923:tile_x1_z1 64 60 64

八、覆蓋與復刻範圍
結構中的空氣會清空 128×80×128 範圍內原有方塊；請放在空地或測試世界。不需要也不應覆蓋 db。
本作品依參考圖重建辨識特徵（弧形立面、壁龕門樓、四馬戰車、鼓座綠頂、舞台塔山牆、露台雕像、燈柱），
不是原作者結構檔。已簡化：曲面以方塊逐格近似、雕像與戰車為方塊造型、藻井以棋盤方塊示意；
背面、兩側後段與全部室內為依風格推測補完。附圖依最終方塊資料繪製，非遊戲截圖。
