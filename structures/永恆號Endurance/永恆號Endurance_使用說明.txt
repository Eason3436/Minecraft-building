永恆號 Endurance（星際效應）末地大廳 — Minecraft 基岩版結構行為包（v2.0.0）

【簡介】
電影《星際效應》(Interstellar) 的環狀太空船「永恆號」，放大成約 200 × 200 的末地大廳。
環直徑 200 格（電影設定 64 m，放大約 3.1 倍），12 個模組圍成一圈、模組間用短通道相連，4 根輻條通到中央樞紐；
樞紐上方停 Ranger 2（偵察穿梭機），下方停 Lander 1（登陸艇）。樞紐中段做成三層挑高的中庭大廳，玩家可以在這裡集合。
設計成懸浮在「末地」的虛空中：外部空氣存成結構空位，不會清掉原地的方塊；艙內都有照明。
附圖：永恆號Endurance_整體渲染.png、永恆號Endurance_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。
※ v2.0.0 取代 v1.0.0（64 格版）。同一個行為包更新，匯入後世界會改用新版；舊版已放置的方塊不受影響。

【尺寸】
寬 200 × 深 200 × 高 104 格（X=200、Y=104、Z=200），切成 4×4 共 16 個分件（每件最大 64 × 104 × 64）。
共 144,032 個方塊、112 種方塊（167 種狀態）；艙內可走的位置約 2 萬格。
方位：環的轉軸是上下方向。上（+Y）＝船頭，下（-Y）＝船尾（12 具引擎噴口朝下）。北（-Z）是指揮艙，順時針排列 12 個模組。
模組：每個 36（切向）× 22（徑向）× 20（高）格。4 個主要艙（指揮艙、居住艙 A、冬眠艙、居住艙 B）有三層甲板，
每層中間是 4 格寬走廊、兩側是房間；推進模組與貨艙是 18 格高的挑高艙。各艙甲板地板高度：原點 Y+44、+50、+56。

【末地大廳（中央樞紐中庭）】
- 直徑 33 格、淨高 23 格（原點 Y+39～Y+61），一樓是大廳地面，上面有三層環形陽台，十字天橋連到中央梯井。
- 一樓：環繞中央梯井的噴水池（底部有海燈籠）、長椅圈、8 組開花杜鵑盆栽、星圖地板、北側接待台（講台＋座椅）、
  一圈任務螢幕牆；東牆是黑洞「卡岡圖雅」（黑色核心＋發光吸積盤），西牆是地球。
- 西南側有大階梯從一樓上到第一層陽台（與 4 根輻條同高），陽台再走輻條就到外環的各艙。
- 天花板垂吊海燈籠吊燈與燈籠；中庭上方兩圈玻璃窗可看外面的環。
- 一鍵傳送到大廳：/execute positioned 300 100 0 run function endurance/lobby（座標換成你放置的原點）。

【匯入與啟用】
1. 開啟（雙擊）永恆號Endurance.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立或編輯世界 → 行為包 → 啟用「永恆號 Endurance（星際效應）」。建議創造模式、開啟作弊（指令）。

【在末地一鍵放置（建議）】
1. 先進入末地（創造模式可用 /execute in the_end run tp @s 300 160 -40）。建議放在離主島中心 300 格外的虛空，
   終界龍不會飛過去撞壞方塊；要當大廳也可以放在主島旁，但請先擊敗終界龍。
2. 在末地輸入（三行原點座標要相同；原點 = 結構西北角最小 X/Y/Z）：
  /execute positioned 300 100 0 run function endurance/prepare
  （等 5～10 秒讓區塊載入）
  /execute positioned 300 100 0 run function endurance/build
  /function endurance/cleanup
   放好後船中心在 (400, 144, 100)：Lander 最低處 Y=100，Ranger 最高處約 Y=203。
   prepare 建立 4 個常駐區塊（tickingarea），build 依序載入 16 個分件，cleanup 移除常駐區塊。
   若某一塊沒出現，通常是區塊尚未載入：站近一點再執行一次 build（重複載入不會壞）。
※ 想放在其他地方，把 300 100 0 換成你要的座標即可。

【逐件放置】
分件 tile_x<i>_z<j>（i、j = 0..3）放在 (原點X + 64i, 原點Y, 原點Z + 64j)。以原點 (300, 100, 0) 為例：
  /structure load endurance_261103:tile_x0_z0 300 100 0
  /structure load endurance_261103:tile_x1_z2 364 100 128
  …共 16 行，完整清單見包內 functions/endurance/build.mcfunction。
  tile_x3_z3 是空的角落（8×8），可以略過。

【已知簡化】
- 電影裡環會旋轉，人造重力朝外；這裡改成重力朝下，地板水平，才能正常走路。
- 12 個模組有 8 個斜放，牆面呈鋸齒；需要床等雙格家具的三層樓艙室放在東西南北四個正向位置。
- 為了容納大廳與三層甲板，比例放大約 3.1 倍；樞紐、Ranger、Lander 一起放大，模組尺寸依劇照估計。
- 設備用功能方塊（偵測器、發射器、合成器、烽火台等）表現外觀，都是靜態，沒有紅石。TARS、CASE 不會動。
- 箱子、木桶、界伏盒沒有物品；水培農場的作物不會自己長大以外的變化。

【注意】
- 艙外空氣是「結構空位」，放置時不會清除原地方塊；艙內空氣會清除。請預留 200 × 200 × 104 的空間。
- 終界龍若還活著、又飛進船裡，可能撞壞方塊；終界使者可能搬走苔蘚、作物等方塊。
- 不要在結構方塊按「儲存」覆蓋同名結構；只需匯入行為包，不需更換 db 或世界檔。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。
