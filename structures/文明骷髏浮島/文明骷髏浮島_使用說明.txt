文明骷髏浮島 — Minecraft 基岩版建築包（26.50）

一、作品
依使用者提供的影片截圖復刻「由許多浮空島拼成骷髏」的創意，並非原作者的逐格原檔。
每一座島代表人類文明的一個階段；從指定觀景點望去，所有島嶼剛好拼成一顆骷髏的正面，
換個角度看則是一座座分開的場景（變形透視錯視）。

  ① 刀耕火種　　左下顎：針葉林沿下顎線、麥田與水圳、兩間茅草屋、風車、營火、樹樁
  ② 古代・中世紀　右下顎：城牆與城門、三座圓塔、半木構民居、水井、街燈、黑色崖壁
　　　　　　　　　 右眼窩：燃燒中的哥德大教堂，玫瑰窗＝瞳孔；雙鐘塔、中殿長椅、祭壇、吊燈
  ③ 工業時代　　鼻孔＝金礦坑口（黃色木框、GOLD 招牌、礦車坑道與金礦石）
　　　　　　　　　 眉心：紅磚鋸齒屋頂工廠（高爐、熔爐）、兩根紅白條紋煙囪
　　　　　　　　　 上排牙＝白色儲油槽；下排牙＝古代石倉；下顎骨＝石拱橋
  ④ 現代科技　　左頰：屋頂綠化的摩天樓群、亮燈窗、巨型 CRT 電腦、紅白電波塔
　　　　　　　　　 左眼窩：巨型渦輪引擎（黑色葉片、紅色熾光、導流錐、天線、彎管）
  ⑤ 未來・太空　頭頂：紫晶尖塔與綠色能量穹頂；右上發射台，太空梭拖著白色尾煙升空
  顱殼：深藍灰色、帶等高線紋的頭蓋骨背板

二、尺寸
主體：寬 112 × 深 64 × 高 150 格（結構座標 X=112、Y=150、Z=64）。
非空方塊 134,930 個，108 種方塊。
因單一結構 X/Z 上限 64，主體切成兩件；另附 9×5×9 的小觀景台。
骷髏正面朝南（+Z）。原點＝包圍盒最小 X/Y/Z 角（西北下角），不是骷髏中心。

三、匯入
1. 開啟「文明骷髏浮島.mcpack」，選 Minecraft 匯入。
2. 世界設定 → 行為包 → 啟用「文明骷髏浮島」。
3. 開啟作弊，建議創造模式（作品浮在空中，需要飛行）。
   最低宣告版本 1.26.50；以 Mojang 官方 v1.26.50.4 方塊表驗證，不保證舊版相容。

四、一鍵放置（建議）
請選一片空曠的天空，建議在海面上方，原點 Y 介於 90～165（頂部會到原點 Y+149）。
下例以原點 (0,110,0) 示範，兩條指令的 0 110 0 請一起改成你選的原點。

第一步：預載區域（作品南北長 165 格含觀景台，避免遠端區塊未載入）
/execute positioned 0 110 0 run function civ_skull/prepare
等待約 5 秒，再執行：
/execute positioned 0 110 0 run function civ_skull/build
build 會依正確偏移載入兩件主體與觀景台，最後移除暫時的常載區域。
若提示區域未載入，重新 prepare 後再 build；若常載區域已達上限，需先騰出一個名額。
取消預載：/function civ_skull/cleanup

五、怎麼看到骷髏（重點）
錯視只在觀景點成立。放置後執行：
/execute positioned 0 110 0 run function civ_skull/view
會把你傳送到觀景台（原點 +56, +74, +160），並面向骷髏中心。
・請站著不要蹲下、不要移動，視線高度剛好對準設計的眼點。
・觀景點距離骷髏背板約 156 格，請把「渲染距離」調到 11 個區塊以上，否則後方的顱殼不會顯示。
・若畫面裝不下整顆骷髏，可稍微調大視野（FOV）。
・離開觀景點、繞到側面，就會看到各個文明是分開的浮空島。

六、手動分件
/give @s structure_block，切到「載入」模式，輸入完整 ID 與下列偏移（不旋轉、不鏡像、完整度 100%）：
  civ_skull_261103:part_01   偏移 (0,0,0)     大小 64×150×64
  civ_skull_261103:part_02   偏移 (64,0,0)    大小 48×150×64
  civ_skull_261103:viewpoint 偏移 (52,70,156) 大小 9×5×9
指令範例（原點 0 110 0）：
  /structure load civ_skull_261103:part_01 0 110 0
  /structure load civ_skull_261103:part_02 64 110 0
  /structure load civ_skull_261103:viewpoint 52 180 156
三件必須使用同一原點、同一朝向，否則從觀景點看不會拼成骷髏。

七、探索路線（本地座標）
・金礦坑道：鼻孔進入，坑道 X=52..60、地面 Y=55、Z=14..52 往北延伸。
・燃燒大教堂：中殿 X=67..82、地板 Y=66、Z=17..44，正門在玫瑰窗下方。
・紅磚工廠：X=50..62、地板 Y=73、Z=30..42，正門朝南。
・茅草屋：X=31..40、Y=45、Z=47..50；風車在 (35,45,55)。
・中世紀城鎮：廣場 Y=51，城門在 (78,52,59)。
・城市與 CRT 電腦：X=10..46、Y=50 起；電腦在 (31..43, 51..61, 27..34)。

八、覆蓋規則與注意
・放置範圍 112×150×64 內的空氣會清空原有方塊，請選空曠天空。
・燃燒效果用營火（會冒煙）、岩漿塊、蕈光與橘紅方塊表現，沒有會蔓延的真火；
  岩漿塊站上去會受傷，營火也會燙傷。
・水只用在封閉的麥田水圳與水井，不會流出島外。
・渦輪葉片、太空梭、引擎火焰為靜態造型，不會轉動或飛行；箱桶未預放物品。
・本包不是世界存檔、不含 db，不需替換世界資料。
