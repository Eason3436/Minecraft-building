國際太空站 ISS — Minecraft 基岩版結構行為包（v1.0.0）

【簡介】
國際太空站 2025 年的構型，比例 1 格 = 1 公尺，桁架、艙段、太陽能翼、散熱器的長度與直徑都照真實數據取整。
設計成懸浮在「末地」的虛空中：外部空氣存成結構空位，不會清掉原地的方塊；艙內自帶照明，末地的黑天也看得清楚。
附圖：國際太空站ISS_整體渲染.png、國際太空站ISS_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。

【尺寸】
寬 112 × 深 88 × 高 36 格（X=112、Y=36、Z=88），切成 2×2 共 4 個分件（最大 64×64）。
共 9,891 個方塊、116 種方塊狀態；艙內可走的空間約 300 格。
方位：北（-Z）= 太空站飛行方向（前方），上 = 天頂，東（+X）= 右舷（S），西（-X）= 左舷（P），下 = 天底（地球方向）。
桁架在 Destiny 正上方東西向橫跨；艙段主軸南北向，高度在原點 Y+20。

【匯入與啟用】
1. 開啟（雙擊）國際太空站ISS.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立或編輯世界 → 行為包 → 啟用「國際太空站 ISS」。建議創造模式、開啟作弊（指令）。

【在末地一鍵放置（建議）】
1. 先進入末地（創造模式可用 /execute in the_end run tp @s 300 140 -20）。建議已擊敗終界龍，
   或像下面一樣放在離主島中心 300 格外的虛空，終界龍不會飛過去撞壞方塊。
2. 在末地輸入三個指令（兩行座標要相同；座標 = 結構西北角最小 X/Y/Z）：
  /execute positioned 300 100 0 run function iss/prepare
  （等 3～5 秒讓區塊載入）
  /execute positioned 300 100 0 run function iss/build
  /function iss/cleanup
   放好後太空站中心大約在 (356, 120, 39)，艙段在 Y=120，桁架在 Y=124～128，最低處 Nauka/Soyuz 約 Y=101。
   prepare 建立 1 個常駐區塊（tickingarea），build 依序載入 4 個分件，cleanup 移除常駐區塊。
   若某一塊沒出現，通常是區塊尚未載入：站近一點再執行一次 build（重複載入不會壞）。
※ 想放在主世界或其他位置也可以，把 300 100 0 換成你要的座標即可（外部空氣是結構空位，不會挖掉地形）。

【逐件放置（結構方塊或指令）】
取得結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入結構名稱（旋轉 0°、無鏡像、完整性 100%）。
自訂原點 (X, Y, Z) 時：分件 tile_x<i>_z<j> 放在 (X+64i, Y, Z+64j)。以原點 (300, 100, 0) 為例（在末地執行）：
  /structure load iss_261103:tile_x0_z0 300 100 0
  /structure load iss_261103:tile_x0_z1 300 100 64
  /structure load iss_261103:tile_x1_z0 364 100 0
  /structure load iss_261103:tile_x1_z1 364 100 64

【已知簡化】
- 走道是 1 格寬、2～3 格高，兩側機櫃 1 格深；真實艙內是約 2 m 見方的走道、四面都是機櫃。
  機櫃用功能方塊（合成器、偵測器、發射器、煙燻爐、講台、鍋釜、鐵砧、砂輪等）表現設備外觀，都是靜態的，沒有紅石。
- 為了讓玩家能通過，艙口一律 1×2 格，小直徑艙段放大到 4 格；Soyuz／Progress 只有 3 格寬，內部只放得下座椅或貨物。
- Quest 的 EVA 外艙門、Kibo 的 JEM 小氣閘、Harmony 天底口、Progress 都是關閉的，避免走出去掉進虛空。
- 太陽能翼只做平放狀態（實際會隨太陽旋轉）；太陽能毯用銅半磚表現金色，iROSA 用藍色陶瓦。
- 曲面以方塊近似；字樣只做幾面國旗（美國、日本、俄羅斯）與 ESA 色塊。
- 艙內的木桶、界伏盒沒有寫入物品內容，是空的。

【注意】
- 艙外的空氣存成「結構空位」，放置時不會清除原地方塊；艙內空氣會清除。請預留 112 × 88 × 36 的空間。
- 終界龍若還活著、又飛進太空站，可能撞壞方塊；植物艙的苔蘚塊與杜鵑可能被終界使者搬走。
- 不要在結構方塊按「儲存」覆蓋同名結構；只需匯入行為包，不需更換 db 或世界檔。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。
