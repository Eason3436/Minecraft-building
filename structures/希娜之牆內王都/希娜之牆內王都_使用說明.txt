希娜之牆內王都 — Minecraft 基岩版結構行為包（v1.0.0）

【簡介】
還原《進擊的巨人》最內層「希娜之牆」以內的世界：只有建築、森林、草原，不含任何人物或巨人。
正中央是王都米特拉斯，希娜之牆在東西南北各突出一個城區：
  東：史托黑斯區　南：艾爾米哈區　北：奧爾布德區　西：亞爾凱爾區
另附一個獨立的「米特拉斯地下街」結構。
附圖：希娜之牆內王都_整體渲染.png、希娜之牆內王都_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。

【比例】
  ・牆高 50 m，房屋、王宮、教堂等建築本體都是 1 格 ＝ 1 公尺。
  ・原作希娜之牆的半徑約 250 km，Minecraft 裡放不下，所以水平距離有壓縮：
    牆半徑 430 格、米特拉斯城牆半徑 175 格，城鎮、村莊、森林只呈現代表性的範圍。
  ・跟上一件「進擊的巨人城牆內世界」相比，這件只做希娜之牆內，同樣的範圍放大約 2.5 倍，建築更密、室內更細。

【尺寸】
寬 1024 × 深 1024 × 高 80 格（X=1024、Y 最高 80、Z=1024），切成 16×16 共 256 個 64×64 分件，
每件高度只裁到該區最高的方塊。共約 783 萬個方塊、180 種方塊。
方位：北（-Z）。結構第 0～2 層是石頭與泥土、第 3 層是地表。
地下街：寬 160 × 深 160 × 高 46 格，切成 3×3 共 9 件。

  ・王宮：北側主殿四層，一二樓打通成王座大廳（黑白棋盤地磚、紅毯、石英柱列、金色王座、紅色掛幔、吊燈），
    兩側是宴會廳、廚房、書房、辦公室與寢室，有樓梯間；主殿上方是鼓座與肋拱圓頂（深色瓦＋金色肋條、頂端燈籠亭），
    正面是石英柱門廊與山牆，左右兩座雙尖塔（內有梯子）；東西側翼、北翼、南翼與四座角樓圍出兩個中庭

  ・一樓依用途擺設，共 13 種：住家廚房／起居、麵包店、酒館、鐵匠、裁縫、書店、蔬果行、藥舖、肉舖、鞋匠、木匠、事務所。

  ・岩盤穹窿、天然石柱、鐘乳石、天花板的蕈光體與螢石，106 棟老舊石造民宅（同樣有室內）、中央廣場與水井、攤位、路燈，
    北側一條 13 格寬的大階梯一路爬到頂端的鐵柵出口。

【一鍵放置（建議，超平坦世界）】
1. 開啟「希娜之牆內王都.mcpack」，用 Minecraft 匯入。
2. 建立或開啟世界，在世界設定裡啟用這個行為包，並開啟作弊（允許指令）。
3. 準備一個 1024×1024 的平坦空地。座標 = 場地西北角（最小 X/Y/Z），原點 Y 用 -64（超平坦世界，地表剛好對齊 -61 的草地）。
以原點 (0, -64, 0) 為例，依序執行（每次的座標都要一樣）：
  /execute positioned 0 -64 0 run function sina/prepare
  （等 3～5 秒讓區塊載入）
  /execute positioned 0 -64 0 run function sina/build1
  （等 3～5 秒）
  /execute positioned 0 -64 0 run function sina/build2
  ……依此類推到 build8（每段放 2 列共 32 個分件，聊天欄會顯示「第 N/8 段完成」）
  /function sina/cleanup
每一段會建立 8 個常駐區塊（tickingarea，每個 128×128）；世界上限 10 個，請先確認你的世界沒有超過 2 個其他常駐區塊。
若某一塊沒出現，通常是區塊尚未載入：走近那一區，再用同樣座標執行一次該段 build（重複載入不會壞）。
一般世界：原點 Y 改成當地地面高度減 3，並先整平 1024×1024 的空地。

【地下街放置】
超平坦世界的地表下只有 3 層，放不下地下街，所以它是獨立結構，請放在別處（例如另一塊空地上，或一般世界的地底）。
以 (2000, -60, 0) 為例：
  /execute positioned 2000 -60 0 run function sina/underground_prepare
  （等 3～5 秒）
  /execute positioned 2000 -60 0 run function sina/underground
地下街四周與上方都是岩石，入口在北側大階梯頂端（z=0 那一面的鐵柵）。

【逐件放置（結構方塊或指令）】
取得結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入結構名稱（旋轉 0°、無鏡像、完整性 100%）。
  地面分件 sina_261103:tile_x<i>_z<j> 放在 (X+64i, Y, Z+64j)，i、j 都是 0～15。
    例：/structure load sina_261103:tile_x0_z0 0 -64 0
        /structure load sina_261103:tile_x7_z8 448 -64 512
  地下街分件 sina_261103:ug_x<i>_z<j> 放在 (X+64i, Y, Z+64j)，i、j 都是 0～2。
完整載入順序就寫在行為包的 functions/sina/build1～build8.mcfunction 裡。

【注意】
  ・結構裡的空氣會清掉原地的方塊，請放在空地上，不要蓋在重要建築上。
  ・只需匯入行為包，不需更換 db 或世界檔。這不是 Java 版 schematic，也不是完整世界。
  ・ID 用 sina_261103 這個新 namespace，不會跟舊的「進擊的巨人城牆內世界」（aot_261102）衝突，兩個可以並存。
  ・一些店舖與宅邸有箱子、木桶，但裡面是空的。
