大阪海遊館 — Minecraft 基岩版結構行為包（v1.0.0）

【簡介】
還原大阪天保山的「海遊館」（1990 年開館，Peter Chermayeff／Cambridge Seven Associates 設計）。
外觀：方盒量體，外牆分三色——底部黑色（地）、中段紅色磁磚（火）、頂部藍色玻璃（水），
四個角像魔術方塊一樣錯位；正面（南面）有藍底魚群與鯨鯊壁畫；屋頂有錯位的玻璃盒與天窗。
館內照真實參觀動線排列：3F 入口 → 水族通道 → 長手扶梯直上 8F 日本森林 → 沿中央「太平洋」大水槽外圍的
螺旋坡道一路往下到 4F（共 4 圈）→ 新體感區 → 下樓到 3F 水母銀河 → 商店 → 出口。
所有水槽都有真的水、底沙、岩礁與植物（海帶、海草、珊瑚、熱帶雨林、日本森林的樹），
遊戲裡沒有的動物用方塊雕像表示，遊戲裡有的動物用真的生物（見【生物】）。
附圖：大阪海遊館_整體渲染.png、大阪海遊館_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。

【尺寸】
寬 96 × 深 128 × 高 64 格（X=96、Y=64、Z=128），平面約 1 格 = 1 公尺，樓層高 5～6 格。
切成 2×2 共 4 個分件（每件 X48 × Z64）。方位：入口與廣場朝南（+Z），北為 −Z。
以結構原點為 (0,0,0)：廣場地面 Y+0，3F 入口 Y+11，4F Y+16，8F 日本森林 Y+40，屋頂 Y+52。

【匯入與啟用】
1. 開啟（雙擊）大阪海遊館.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立或編輯世界 → 行為包 → 啟用「大阪海遊館」。
3. 世界要開啟「作弊」（指令）。建議用超平坦或先整地，需要 96 × 128 的平地。

【一鍵放置（建議）】
以原點 0 -61 0（超平坦世界：廣場剛好取代最上層草地）為例，依序執行：
  /execute positioned 0 -61 0 run function kaiyukan/prepare
  （等 3～5 秒讓區塊載入）
  /execute positioned 0 -61 0 run function kaiyukan/build
  /execute positioned 0 -61 0 run function kaiyukan/animals     ← 放入真實生物（魚、海豚、海龜…）
  /function kaiyukan/cleanup
參觀：
  /execute positioned 0 -61 0 run function kaiyukan/tour          → 傳送到正門廣場
  /execute positioned 0 -61 0 run function kaiyukan/tour_pacific  → 傳送到螺旋坡道、面對太平洋大水槽
想移除所有生物：/function kaiyukan/clear_animals
※ 一般主世界請把 0 -61 0 換成地面座標（例如 0 64 0）。若某一塊沒出現，站近一點再執行一次 build。
※ animals 只能執行一次（重複執行會多一倍生物）；生物都有名牌，不會自然消失。

【逐件放置（結構方塊或指令）】
取得結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入結構名稱（旋轉 0°、無鏡像）。
分件 tile_x<i>_z<j> 放在 (X+48i, Y, Z+64j)。以原點 (0, -61, 0) 為例：
  /structure load kaiyukan_261110:tile_x0_z0 0 -61 0
  /structure load kaiyukan_261110:tile_x0_z1 0 -61 64
  /structure load kaiyukan_261110:tile_x1_z0 48 -61 0
  /structure load kaiyukan_261110:tile_x1_z1 48 -61 64
逐件或用建築放置台放置後，仍要在原點執行 kaiyukan/animals 才會有真實生物。
也可用「建築放置台」放置（啟用本包後會自動出現在選單）。

【參觀路線】（館內有告示牌標示每個展區）
1. 正門：廣場兩座大階梯（左入口、右出口），兩旁是水池；上到 3F 平台進入大廳（票閘、服務台、鯨鯊看板）。
2. 3F 水族通道 Aqua Gate：玻璃隧道穿過熱帶魚水槽（珊瑚、20 隻熱帶魚）。
3. 長手扶梯：從 3F 一路上到 8F，旁邊是挑高中庭與吊燈。
4. 8F 日本森林：玻璃天窗下的森林，西側瀑布→溪流→小爪水獺池，東側有大山椒魚與夜鷺的池塘、木棧道、青蛙。
5. 入口天橋 → 螺旋坡道：繞中央太平洋大水槽順時針往下走 4 圈（8F→7F→6F→5F→4F），每圈下降 6 格，用半磚做成緩坡。
   外圈每個水槽跨兩層：上一圈看水面與陸地，下一圈看水中。
   ‧ 第 1、2 圈：阿留申群島（岩礁、海帶、海獺、角海鸚）→ 蒙特雷灣（海帶森林、加州海獅、斑海豹）→
     巴拿馬灣（刺魨）＋厄瓜多熱帶雨林（叢林樹、巨骨舌魚、食人魚、水豚）→ 南極大陸（雪地、浮冰、國王／巴布亞／阿德利企鵝）→
     塔斯曼海（5 隻海豚）
   ‧ 第 3、4 圈：大堡礁（珊瑚礁、熱帶魚）→ 瀨戶內海（章魚、伊勢龍蝦、真鯛）→ 智利海岸（30 隻沙丁魚群）→
     庫克海峽（赤蠵龜）→ 日本海溝（昏暗深海、甲殼蜘蛛蟹、發光魷魚）
   ‧ 內側一路看著太平洋大水槽：鯨鯊 ×2、鬼蝠魟 ×2、雙髻鯊 ×2、翻車魨，以及沙丁魚、黑鮪魚、熱帶魚群。
     8F 那圈從上方看水面，6F～4F 隔著玻璃看水中。
6. 4F 出口通道 → 新體感區：北極（環斑海豹＋浮冰）、福克蘭群島（跳岩企鵝）、馬爾地夫觸摸池（淺池、魟魚、小魚）。
   4F 西側有特別展示室。
7. 東北角樓梯下到 3F 水母銀河（暗室、發光的水母柱）→ 商店（鯨鯊布偶、紀念品架）→ 出口大門 → 右側大階梯回廣場。

【生物】
真實生物（kaiyukan/animals 放入，共 188 隻，都在水裡或森林地面上）：
  海豚 5、赤蠵龜 4、熱帶魚、鱈魚（當沙丁魚）、鮭魚（當黑鮪魚／食人魚）、河魨（刺魨）、魷魚（章魚）、發光魷魚、青蛙。
方塊雕像（遊戲沒有的動物）：鯨鯊、鬼蝠魟、雙髻鯊、翻車魨、企鵝、加州海獅、斑海豹、環斑海豹、海獺、小爪水獺、
  角海鸚、水豚、巨骨舌魚、甲殼蜘蛛蟹、伊勢龍蝦、大山椒魚、夜鷺、水母。

【已知簡化】
- 平面約 1:1，但為了讓走道有頭部空間，樓層高（每圈 6 格）比真實略高；太平洋大水槽 32×32、水深 18 格（真實約 34 m 長、9 m 深）。
- 真實螺旋坡道是連續斜坡，這裡用「每 1 格高差配半磚」的緩坡呈現；實際形狀簡化為正方形環。
- 外牆魚群壁畫是依照「藍底魚群」的意象重畫的，不是原作逐格複製；5F～7F 東側是工作人員區（備用水槽、過濾機房），沒有對外開放。
- 企鵝、海獅等雕像不會動；水母用玻璃塊表示。
- 遊戲中魚類可能在水槽間游到玻璃邊，不會逃出；海豚池上方有 2 格玻璃欄杆。

【注意】
- 結構中的空氣會清除原地方塊；請預留 96 × 128 × 64 的空間。
- 瀑布是流動水方塊，載入後會自然流到下方水池。
- 不要在結構方塊按「儲存」覆蓋同名結構；只需匯入行為包，不需更換 db 或世界檔。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。
