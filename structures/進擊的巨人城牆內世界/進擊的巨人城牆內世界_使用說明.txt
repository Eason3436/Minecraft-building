進擊的巨人城牆內世界 — Minecraft 基岩版結構行為包（v1.0.0）

【簡介】
還原《進擊的巨人》帕拉迪島「城牆之內」的世界：只有建築、森林、草原，不含任何人物或巨人。
三道同心巨牆由外而內為瑪利亞之牆、羅塞之牆、希娜之牆，正中央是王都米特拉斯。
附圖：進擊的巨人城牆內世界_整體渲染.png、進擊的巨人城牆內世界_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。

【比例】
  ・三道牆的半徑依原作設定 480 km：380 km：250 km 等比縮小為 330：261：172 格
    （水平方向約 1 格 ＝ 1.45 km，三道牆彼此的相對大小是正確的）。
  ・牆高 50 m、房屋、王宮、教堂等建築本體是 1 格 ＝ 1 公尺。
  ・因此城區、村莊、森林只呈現代表性的街區，實際原作的城市會大上許多倍；這是為了在 Minecraft 裡放得下所做的取捨。

【尺寸】
寬 768 × 深 768 × 高 59 格（X=768、Y 最高 59、Z=768），切成 12×12 共 144 個 64×64 分件，
每件高度只裁到該區最高的方塊。共約 564 萬個方塊、115 種方塊。
方位：北（-Z）在上，南（+Z）是希干希納區與托洛斯特區。結構第 0 層是石頭、第 3 層是地表草地。

【內容】
  三道巨牆：牆高 50 格、厚 7 格，內外兩側每隔一段有扶壁（下段加寬成階梯狀），牆頂有走道、護欄與垛口，
    牆面用方解石、閃長岩、平滑石、安山岩、凝灰岩混色表現風化污漬。
  12 個城區：每道牆在東西南北各突出一個半圓形城區，城區有自己的城牆、外門與內門。
    外門有門框、拱頂鍵石、升起的吊閘、金色牆徽、沿牆面直上的升降架與牆頂機房；城區牆頂有固定砲。
    城區名稱（括號為正方位）：
      瑪利亞之牆：希干希納區（南）、瑪利亞東城區、瑪利亞北城區、瑪利亞西城區
      羅塞之牆：托洛斯特區（南）、卡拉內斯區（東）、羅塞北城區、羅塞西城區

    城區內有主街、橫街、廣場噴泉、街燈、教堂（鐘樓與尖頂，瑪利亞與羅塞城區），

    木地板、樓板、梯子、吊燈、桌椅、工作台、熔爐、箱子、書架、二樓床鋪。

    王宮：北側四層主殿（一二樓打通的王座大廳，紅毯、金色王座、石柱、吊燈）、

          正面拱門通道與雕像柱廣場、翼端階梯山牆；
    北側幾何花園（樹籬格紋、放射狀碎石步道、圓形噴泉、柏樹列）；
    城內 169 棟石造連棟屋（3～5 層）、運河（石砌堤岸、欄杆、街燈）與多座石橋、運河旁市集廣場（噴泉、彩色布篷攤位）。
  河流：從東北穿過三道牆的水門（拱形開口＋鐵柵）流進米特拉斯運河，再往西南流出。
  鄉間（牆與牆之間）：9 個村莊（水井、菜園、風車或小教堂，共 58 棟）、394 塊麥田／胡蘿蔔／馬鈴薯田（含灌溉水渠、乾草捆、樹籬）、
    森林約 4200 棵（橡樹、白樺、雲杉、深色橡樹、柏樹）、草原的草叢與野花、湖。

    烏特加爾古城（羅塞之牆內，半毀方塔與圍牆）、巨大樹森林（瑪利亞之牆內西南，10 棵高 34～44 格的巨木）。

【一鍵放置（建議，超平坦世界）】
請準備一個 768×768 的平坦空地。座標 = 場地西北角（最小 X/Y/Z），原點 Y 用 -64（超平坦世界，地表會剛好對齊 -61 的草地）。
以原點 (0, -64, 0) 為例，依序執行（兩組座標都要一樣）：
  /execute positioned 0 -64 0 run function aot/prepare
  （等 3～5 秒讓區塊載入）
  /execute positioned 0 -64 0 run function aot/build1
  （等 3～5 秒）
  /execute positioned 0 -64 0 run function aot/build2
  ……依此類推到 build6（每段放 2 列共 24 個分件，聊天欄會顯示「第 N/6 段完成」）
  /function aot/cleanup
每一段會建立 6 個常駐區塊（tickingarea，每個 128×128）；世界上限 10 個，請先確認你的世界沒有超過 4 個其他常駐區塊。
若某一塊沒出現，通常是區塊尚未載入：走近那一區再用同樣座標執行一次該段 build（重複載入不會壞）。
一般世界：原點 Y 改成當地地面高度減 3，並先整平 768×768 的空地。

【參觀路線】（括號內是相對原點的 X, Z；地面高度在結構第 4 層，超平坦即 Y=-60）
  1. 希干希納區外門 (384, 758)：看外門升降架、吊閘、牆徽；進城區看廣場噴泉與教堂。
  2. 往北穿過內門到瑪利亞之牆內，再到托洛斯特區外門 (384, 685)，城區中心約 (384, 662)。
  3. 托洛斯特區東北邊的訓練兵團本部 (492, 571)；西南邊是巨大樹森林 (約 243, 649)。
  4. 繼續往北：艾爾米哈區 (384, 572 附近) → 希娜之牆內 → 米特拉斯南門 (384, 484)。
  5. 米特拉斯：運河石橋 (384, 462)、王宮正面廣場 (384, 420)、中庭 (384, 390)、王座大廳 (384, 368)、
     圓頂 (384, 364)、北側幾何花園 (384, 327)、運河旁市集廣場 (448, 380)。
  6. 其他：烏特加爾古城 (276, 198)、西北方的湖 (126, 235)、卡拉內斯區 (東，645, 384)、斯托黑斯區 (東，556, 384)。
  爬上城牆：牆頂有走道，可從城區外門的牆頂機房看整片城牆。

【空氣與地形】
每個分件的空氣會清空原有方塊（例如草叢、樹），結構第 0～3 層包含石頭、泥土與草地。
不要在已有建築的地方放置。只需匯入行為包，不需更換 db 或世界檔。此檔為基岩版行為包，不是 Java 版 schematic。
