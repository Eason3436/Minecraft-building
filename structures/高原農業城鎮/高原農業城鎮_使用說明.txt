高原農業城鎮 — Minecraft 基岩版結構行為包（v1.0.1）

【簡介】
一座建在高原台地上的農業小鎮，風格取材自真實的阿爾卑斯／南德高原農村（瑞士高原、巴伐利亞）：
白灰泥牆配石砌勒腳、深色木造上層與木陽台、窗邊百葉與花箱、寬簷緩坡瓦頂；鎮中心有洋蔥頂教堂與市集廣場；
四周是田地、牧場、果園，東南坡是一階一階的梯田。四條礦車鐵路在台地上下交織：
幹線沿山坡爬上高原、穿過山丘隧道、跨過峽谷石拱高架橋；低地的農用輕便鐵道兩次從幹線橋下穿過。
附圖：高原農業城鎮_整體渲染.png（從東北方俯瞰）、高原農業城鎮_內部剖視.png（鎮中心切在地面層）。
附圖依方塊資料繪製，非遊戲截圖；方塊形狀有簡化。

【尺寸】
寬 256 × 深 256 × 高 64 格（X=256、Y=64、Z=256），切成 4×4 共 16 個分件（每件 64×64×64）。
設計給「超平坦」世界：結構最底層 = 基岩（Y=-64），四周低地地面與超平坦草地同高，接縫看不出來。
低地地面在結構 Y=3（世界 Y=-61），高原台面在結構 Y=27（世界 Y=-37），高差 24 格。
方位：北（-Z）是車站與幹線，南（+Z）是梯田與南側低地；共約 1,264,524 個方塊、103 種方塊。

【場景內容】
一、鐵路（礦車軌道；坡段用動力鐵軌，下方藏紅石磚供電）
  ・A 幹線：東緣低地進場 → 沿東北山坡的路堤爬升 24 格（坡度 1:3）→ 高原車站（兩股道、島式月台、
    站房月台雨棚、長椅、月台燈）→ 西北「禮拜堂山」隧道（石砌隧道口、洞內吊燈）→
    西側峽谷石拱高架橋（谷底約 24 格深，多孔石拱）→ 沿西緣山坡下降 → 西南角低地出場。
  ・A2 待避線：車站第二股道，兩端以道岔接回幹線。
  ・B 貨運支線：車站東側分岔，經貨棚卸貨月台到農會穀倉筒倉下方。
  ・D 田園環線：從貨運支線往南，穿過東部田區，在東南田區繞一圈（氣球線）。
  ・C 農用輕便鐵道（低地）：東南梯田腳 → 沿東緣北上，在東北角從幹線路堤橋下穿過 →
    沿北側低地農田西行（經過北側農莊）→ 沿西緣南下 → 進入峽谷谷底，從幹線高架橋下穿過，終點在峽谷中。
  ・道岔：車站兩端、貨運支線分岔、環線入口旁各有一支拉桿，拉下即可切換道岔方向（預設走直線／幹線）。
二、鎮中心
  ・市集廣場：石板拼花鋪面、圓形噴泉、路燈。
  ・洋蔥頂教堂：西側鐘塔（鐘、四面時鐘、銅綠洋蔥頂）、中殿長椅與紅色走道、半圓後殿祭壇與蠟燭、吊燈。
  ・市政廳（三層，屋脊鐘塔）、旅店 Gasthof（三層，一樓酒館、樓上客房）、郵局、麵包店、肉舖、雜貨店、學校、
    以及十多棟兩層民宅（一樓廚房餐桌、二樓臥室、梯子上下、閣樓），陽台花箱、煙囪冒炊煙。
三、車站與農業設施
  ・車站站房（候車室長椅、售票櫃台、站長室），水塔、貨棚與卸貨月台。
  ・農會穀倉：六座水泥筒倉（內存乾草）、頂部輸送樓、斗升機塔、往側線的裝車溜槽。
  ・酪農場（起司工坊）。
四、農村
  ・一體式農舍 ×5（住屋與穀倉同一屋頂：住屋兩層，穀倉有牛欄、水槽、乾草閣樓、大門）、北側低地農莊。
  ・麥田、馬鈴薯、紅蘿蔔、甜菜根田（每塊田中央有灌溉水渠）、牧場（柵欄、水槽、乾草捆）、
    草原（乾草捆、野花）、果園（蘋果樹、蜂箱）、稻草人、田間乾草棚。
  ・東南梯田：8 階、每階 3 格高，乾砌石擋土牆、後緣水渠、分層種不同作物。
  ・峽谷小溪、禮拜堂山頂的小禮拜堂、雲杉林、崖坡樹林。

【匯入與啟用】
1. 開啟（雙擊）高原農業城鎮.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立新世界：世界類型選「超平坦」，建議創造模式、開啟作弊（指令）。在「行為包」啟用「高原農業城鎮」。

【一鍵放置（建議）】
在世界中輸入以下指令（座標要相同；座標 = 結構西北角最小 X/Y/Z，Y 一定要 -64）：
  /execute positioned 0 -64 0 run function highland/prepare
  （等 5～10 秒讓區塊載入）
  /execute positioned 0 -64 0 run function highland/build
  /execute positioned 0 -64 0 run function highland/life     ← 選用：放出牛、羊、馬、雞、豬、貓
  /execute positioned 0 -64 0 run function highland/carts    ← 選用：在車站、輕便鐵道、環線放 4 台礦車
  /function highland/cleanup
prepare 建立 4 個常駐區塊（tickingarea），build 依序載入 16 個分件，cleanup 移除常駐區塊。
若某一塊沒出現，通常是區塊尚未載入：飛近那一區再執行一次 build（重複載入不會壞）。
life、carts 每執行一次就會多一批，各執行一次即可。
※ 想放在別的位置，把指令裡的 0 -64 0 換成同一組座標即可（X、Z 自訂，Y 維持 -64）。
※ 世界中常駐區塊上限是 10 個，若已用掉 7 個以上，prepare 會有幾區建立失敗，請先移除舊的。
也可以用「建築放置台」附加包放置（選單中選「高原農業城鎮」）。

【逐件放置（結構方塊或指令）】
取得結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入結構名稱（旋轉 0°、無鏡像、完整性 100%）。
分件 highland_261109:tile_x<i>_z<j>（i、j = 0～3）放在 (X+64i, -64, Z+64j)。例：
  /structure load highland_261109:tile_x0_z0 0 -64 0
  /structure load highland_261109:tile_x2_z1 128 -64 64
  /structure load highland_261109:tile_x3_z3 192 -64 192

【已知簡化】
- 鐵路用原版礦車軌道表現，沒有真正的火車；鐵軌、枕木改用碎石路基表現。
- 坡道用 1:3（每 3 格升 1 格），比真實山岳鐵路陡；坡段每一格斜軌都是動力鐵軌，下方的紅石磚是電源，不要拆。
- 道岔是「T 形軌道＋拉桿」，礦車只會走拉桿目前設定的方向。
- 蘋果樹用橡樹＋開花杜鵑葉表現；起司、牛奶用鍋釜、木桶示意；水泥筒倉內只放乾草塊。
- 箱子、木桶沒有放物品；告示牌沒有文字；動物需執行 life 才會出現。

【注意】
- 結構內的空氣會清除原地方塊，請在空曠的超平坦世界放置，預留 256 × 256 的範圍。
- 載入會把 Y=-64 那層也寫成基岩（與超平坦相同）。
- 不要在結構方塊按「儲存」覆蓋同名結構；只需匯入行為包，不需更換 db 或世界檔。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。
