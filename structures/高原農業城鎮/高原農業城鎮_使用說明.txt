高原農業城鎮 — Minecraft 基岩版結構行為包（v2.0.1）

【簡介】
一座建在阿爾卑斯高原上的農業小鎮，風格取材自真實的瑞士高原與巴伐利亞山村：
白灰泥牆配石砌勒腳、深色木造上層與木陽台、窗邊百葉與花箱、寬簷瓦頂；鎮中心有洋蔥頂教堂、市政廳與市集廣場。
v2 重做了整片地形：北側是積雪的岩石稜線，高原本身高低起伏、散布丘陵，東南有一條河谷切下去；
房子、農舍、田地都依當地地形高度擺放，山坡上的田沿著等高線一條一條排列，陡坡與山腳是雲杉林。
鐵路沿著地形蜿蜒：幹線沿河谷慢慢爬上高原、在西側繞一個馬蹄形大彎進站，再往南繞一圈、用石拱高架橋跨過
自己底下的那段軌道與河谷；山線從車站出發，繞著一座小山螺旋爬升（下圈走隧道、上圈用跨線橋從自己頭上越過），
最後沿雪山山腳到高山牧場的招呼站。

附圖依方塊資料繪製，非遊戲截圖；方塊形狀有簡化。

【尺寸】
寬 256 × 深 256 × 高 96 格（X=256、Y=96、Z=256），切成 4×4 共 16 個分件（每件 64×96×64）。
設計給「超平坦」世界：結構最底層 = 基岩（Y=-64），四周邊緣的地面與超平坦草地同高，接縫看不出來。
地形高度：邊緣低地約結構 Y=3～8，河谷底 Y=3～25，高原 Y=25～47，雪山稜線最高約 Y=69（世界 Y=5）。
車站軌面在結構 Y=31（世界 Y=-33）。方位：北（-Z）是雪山，南（+Z）是河谷與南丘。
共約 1,479,572 個方塊、103 種方塊。

【場景內容】
一、鐵路（礦車軌道；坡段用動力鐵軌，下方藏紅石磚供電）
  ・A 幹線（約 620 格）：東南角低地進場 → 沿河谷北岸蜿蜒爬升約 27 格 → 西側山丘的馬蹄形大彎（一段走隧道）
    → 高原車站 → 往南繞一個大 S 彎 → 石拱高架橋從自己先前爬坡的那段軌道與河谷上方跨過 → 南丘
    → 沿南坡長高架橋下降 → 南緣低地出場。
  ・C 山線（約 290 格）：從車站第二股道出發 → 往東北 → 繞「螺旋山」整整一圈爬升（下圈穿山隧道，
    上圈從自己頭上的跨線橋越過）→ 沿雪山山腳往西繼續爬 → 終點高山牧場招呼站（結構 Y=46，比車站高 15 格）。
  ・B 貨運側線：車站東端分岔往南，到農會穀倉筒倉的裝車溜槽下方。
  ・道岔：山線、貨運側線與幹線相接處各有一支拉桿（裝飾）；礦車預設走幹線。
  ・隧道有石砌洞門、洞內吊燈；高架橋為多孔石拱，橋面兩側石牆欄杆與燈。
二、車站與鎮中心
  ・車站：兩股道、島式月台與站房側月台（雨棚、長椅、月台燈）、站房（候車室、售票櫃台、站長室）、水塔。
  ・市集廣場：順著坡度鋪石，圓形噴泉與路燈。
  ・洋蔥頂教堂（建在西側小丘上）：鐘塔、四面時鐘、銅綠洋蔥頂、中殿長椅、半圓後殿祭壇與蠟燭。
  ・市政廳（三層＋屋脊鐘塔）、旅店 Gasthof（三層）、郵局、麵包店、肉舖、雜貨店、數棟兩層民宅。
    房子依地形各自決定地基高度，屋脊順著等高線、大門開在下坡側；地基四周的土坡會順成緩坡接上。
三、農業
  ・農會穀倉：六座水泥筒倉、頂部輸送樓、斗升機塔、往貨運側線的裝車溜槽；旁邊有貨棚。
  ・一體式農舍 ×8：散在起伏的田野與山坡上（住屋與穀倉同一屋頂）。
  ・田地沿等高線分塊：麥田、馬鈴薯、紅蘿蔔、甜菜根（田中有灌溉水格）、牧場（柵欄圍起）、
    開花草原、果園；田間乾草棚、田埂小徑。
  ・東南河谷的河流（河床有小堰）、河邊樹林、陡坡雲杉林、山頂小禮拜堂、雪線以上的積雪。

【匯入與啟用】
1. 開啟（雙擊）高原農業城鎮.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
   已裝過 v1 的話，這版會直接更新同一個行為包（版本 2.0.1）。
2. 建立新世界：世界類型選「超平坦」，建議創造模式、開啟作弊（指令）。在「行為包」啟用「高原農業城鎮」。

【一鍵放置（建議）】
在世界中輸入以下指令（座標要相同；座標 = 結構西北角最小 X/Y/Z，Y 一定要 -64）：
  /execute positioned 0 -64 0 run function highland/prepare
  （等 5～10 秒讓區塊載入）
  /execute positioned 0 -64 0 run function highland/build
  /execute positioned 0 -64 0 run function highland/life     ← 選用：放出牛、羊、馬、雞、貓
  /execute positioned 0 -64 0 run function highland/carts    ← 選用：在兩股道、貨運側線、幹線起點放 4 台礦車
  /function highland/cleanup
prepare 建立 4 個常駐區塊（tickingarea），build 依序載入 16 個分件，cleanup 移除常駐區塊。
若某一塊沒出現，通常是區塊尚未載入：飛近那一區再執行一次 build（重複載入不會壞）。
※ 想放在別的位置，把指令裡的 0 -64 0 換成同一組座標即可（X、Z 自訂，Y 維持 -64）。
※ 世界中常駐區塊上限是 10 個，若已用掉 7 個以上，prepare 會有幾區建立失敗，請先移除舊的。
也可以用「建築放置台」附加包放置（選單中選「高原農業城鎮」）。

【逐件放置（結構方塊或指令）】
分件 highland_261109:tile_x<i>_z<j>（i、j = 0～3）放在 (X+64i, -64, Z+64j)。例：
  /structure load highland_261109:tile_x0_z0 0 -64 0
  /structure load highland_261109:tile_x2_z1 128 -64 64

【已知簡化】
- 鐵路用原版礦車軌道表現，沒有真正的火車；枕木改用碎石路基表現。
- 坡道最陡每 2 格升 1 格，比真實山岳鐵路陡；斜軌都是動力鐵軌，下方的紅石磚是電源，不要拆。
- 斜向行進的軌道在方塊世界只能走成鋸齒狀；只有直線格能升降，所以彎道上的軌道是平的。
- 河是靜止水源方塊，高低落差處用石塊做成小堰。
- 箱子、木桶沒有放物品；告示牌沒有文字；動物需執行 life 才會出現。

【注意】
- 結構內的空氣會清除原地方塊，請在空曠的超平坦世界放置，預留 256 × 256 的範圍、高 96 格。
- 載入會把 Y=-64 那層也寫成基岩（與超平坦相同）。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。
