亞特蘭提斯太空梭 — Minecraft 基岩版結構行為包

內容：依參考圖片製作的大型直立太空梭組合，含橘色外燃料箱、雙側助推器、三角翼、黑色隔熱邊、三具引擎噴嘴及展示平台。太空梭內有機械艙、衛星貨艙、實驗層、生活艙及駕駛艙，連續爬梯串接五層。

附圖依建築方塊資料繪製，非遊戲截圖；材質或局部方塊形狀可能簡化。
尺寸：寬 61 × 深 53 × 高 172 格（結構方塊 X=61、Y=172、Z=53）。
行為包宣告最低版本：1.21.70；此宣告不代表已在該版本實測。

使用方法
1. 開啟 亞特蘭提斯太空梭.mcpack，用 Minecraft 匯入。
2. 在目標世界設定中，啟用剛匯入的行為包。
3. 在允許指令的世界取得結構方塊：/give @s structure_block
4. 放置結構方塊，切换成「載入」，輸入：shuttle_260915:atlantis
5. 載入預覽並確認位置，再放置建築。
也可執行 /structure load shuttle_260915:atlantis 100 64 100
這是示例座標，請換成自己的空地位置。

擺放：原點為平台最小 X/Y/Z 角，太空梭正面朝 -Z（北），登艙走橋在 -X（西）側。建議原點 Y=64，最高點為 Y=235。平台地板 Y+3，登艙平台與機械艙地板 Y+31；貨艙 Y+43、實驗層 Y+64、生活艙 Y+85、駕駛艙 Y+101。
請預留 61 × 53 × 172 格空間。結構中的空氣會清空原有方塊；索引 -1 才保留原地形。
不要按儲存來覆蓋已有結構。只需匯入行為包，不需更換 db 或世界檔。
此檔為基岩版行為包，不是 Java 版 schematic，也不是完整世界。

驗證：已重新解析 NBT、檢查尺寸與索引、驗證包內結構一致及 ZIP CRC。
尚未在 Minecraft 客戶端實際載入測試；方塊名稱與版本相容性另依建模時官方表檢查。

整組載入
只有一個結構名稱：shuttle_260915:atlantis
取得結構方塊：/give @s structure_block
切換「載入」，輸入完整名稱；旋轉 0 度、無鏡像、完整性 100%。
整組尺寸 X=61、Y=172、Z=53。建議在主世界開闊地以原點 Y=64 放置，最高方塊 Y=235。

如何進入內部（以下都是相對整體原點的偏移）
1. 到西側外梯 (X+8、Y+4、Z+14)，沿梯爬上登艙走橋。
2. 登艙平台地板 Y+31，沿 +X 走到側艙口，約 (X+23、Y+32、Z+14)。
3. 進入機械艙後走向後方，內爬梯位於 (X+30、Z+18)，由 Y+31 連續通往 Y+108。
4. 各層地板高度：機械艙 Y+31、衛星貨艙 Y+43、實驗層 Y+64、生活艙 Y+85、駕駛艙 Y+101。
5. 從內爬梯朝 -Z 方向離開，可走入各層。
若原點為 (100,64,100)，側艙口約為 (123,96,114)，駕駛艙可站立區約為 (130,166,114)。

內部細節
機械艙：雙側機組、管線、發光面板和檢修通道。
貨艙：金色衛星本體、藍色太陽能板、天線、吊架與貨箱造型。
實驗層：雙側工作台、樣本設備、藍色顯示器與照明。
生活艙：四張上下舖造型、白色枕頭、置物櫃和簡易料理台。
駕駛艙：兩張駕駛座造型、前方儀表、雙螢幕、側電子設備及外側玻璃窗。
本次為直立姿態下可探索的創作內裝，並非真實太空梭內部的精確工程復刻。
可探索內部集中在白色太空梭本體；外燃料箱與兩側助推器是實心外觀結構。
此為靜態原版方塊建築，不含飛行、發射或爆炸機制。
爬梯可攀爬，海燈籠可照明；臥鋪、座椅、貨箱、儀器和螢幕均為造型，不提供睡眠、坐姿或操作功能。

覆蓋範圍
中央組合的空氣包圍範圍為 X+3..57、Y+4..171、Z+0..45，會清空該範圍內未放建築的原有方塊。
平台及建築實體方塊覆蓋其位置，其他未使用格採 -1 保留地形。
請選擇足夠空曠的場地；圖片中的展示館背景不包含在建築內。
