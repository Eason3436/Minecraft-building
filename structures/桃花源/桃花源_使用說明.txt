桃花源 — Minecraft 基岩版結構行為包（v1.0.0）

【簡介】
依陶淵明《桃花源記》還原整段路線。由南往北走一遍，就是整篇文章的順序：
  緣溪行 → 忽逢桃花林，夾岸數百步，中無雜樹，芳草鮮美，落英繽紛 → 林盡水源，便得一山 →
  山有小口，彷彿若有光 → 便舍船，從口入 → 初極狹，纔通人 → 復行數十步，豁然開朗 →
  土地平曠，屋舍儼然，有良田美池桑竹之屬，阡陌交通，雞犬相聞 → 便要還家，設酒殺雞作食 →
  既出，得其船，便扶向路，處處誌之
附圖：桃花源_整體渲染.png、桃花源_內部剖視.png（依方塊資料繪製的示意圖，非遊戲截圖）。

【尺寸】
寬 256 × 深 320 × 高 80 格（X=256、Y=80、Z=320），切成 4×5 共 20 個分件（每件 64×80×64）。
設計給「超平坦」世界：結構最底層 = 基岩層（Y=-64），地圖邊緣地形收到超平坦草地高度，接縫看不出來。
方位：北（-Z）是村落所在的盆地，南（+Z）是桃花溪下游；漁人從南邊順溪而上。
共約 220 萬個方塊（大多是山體內部的石頭），123 種方塊、289 種方塊狀態。

【場景內容】
一、桃花溪（南段，Z 200～319）
  ・溪流蜿蜒 120 格，寬 7～13 格，沙、礫石、黏土河床；岸邊蘆葦、水面睡蓮。
  ・兩岸 30 格內只種桃樹（中無雜樹）：百餘棵櫻桃木桃樹，短幹斜枝、團狀粉色樹冠、有垂下的花枝。
  ・地上鋪滿落花（粉紅花瓣）、野花、草叢（芳草鮮美，落英繽紛）；林外山坡才有松樹與雜木。
  ・溪東岸有一條小路，沿路每隔 24 格一座「誌記石堆」（苔石＋石牆＋紅布），對應「處處誌之」。
二、林盡水源・山有小口（Z 184～200）
  ・溪流源頭是山腳下的水源池；池邊停著漁人的小木船（船上有木桶、船燈），旁邊有小渡口棧板。
  ・山崖上一個只有 1 格寬、2 格高的小洞口，四周長滿青苔。
  ・隧道筆直往北 43 格：前 15 格 1×2「初極狹，纔通人」，之後漸寬到 3、5、9 格，地面緩緩爬升 7 格，
    出口是寬闊的山口。因為是直的，站在洞口往裡看，能看到另一端的光（彷彿若有光）。
三、桃花源村（北段盆地，地面 Y=-52）
  ・四面石灰岩峰林環抱（綠頂灰崖、松樹、崖壁垂藤），東北角一道 30 格高的瀑布落入深潭。
  ・溪水從瀑布潭流經祠堂前，繞過村子西北注入「美池」，再往南沒入山腳。
  ・屋舍儼然：4×4 棋盤格，15 座院落＋1 處曬穀場，主街南北向、三條東西巷，主街燈柱、行道桃樹。
    每座院落：正房三間（中間堂屋、兩側臥室或織房）＋東廂廚房（灶、煙燻爐、水缸、酒罈、屋頂煙囪冒炊煙）
    ＋西廂倉房（乾草、石磨、木桶、堆肥桶）或蠶房（竹架蠶匾）或菜圃；夯土牆、石牆基、木柱分間、
    茅草頂（竹馬賽克階梯＋乾草屋脊）或灰瓦頂；院牆有夯土牆門樓或竹籬笆。
    院內小景隨機：雞窩、狗窩、曬架、水缸醃菜罈、花圃、石磨、小桃樹。
  ・漁人作客的人家（主街東側第三排）：堂屋供桌、方桌椅、兩間織房、雞窩。
  ・祠堂（村北、石橋過溪）：灰瓦重簷、格扇門、祖先供桌與蠟燭、兩排長桌筵席（糕點、酒罈、蠟燭），
    院中香爐、燈柱——「設酒殺雞作食」「餘人各復延至其家，皆出酒食」。
  ・古井亭（主街十字口）、村口老樟樹（2×2 粗幹）、曬穀場與圓形茅頂穀倉、石碾。
  ・水車磨坊：溪中立著直徑 9 格的水車，輪軸穿進磨坊，屋內石磨、糧桶。
  ・美池：荷葉滿池、垂柳環岸，水上茅頂涼亭（木棧道相連，亭內小桌）。
  ・良田：村子四周的麥田、紅蘿蔔、馬鈴薯、甜菜根田，每塊田中間一條灌溉水渠；插秧後的水田（水草）。
  ・阡陌交通：田與田之間是土徑田埂，東西向的大路通往東邊梯田。
  ・東側山腳的梯田（一階一層水田）、西南的桑園、北側山腳的竹林、村邊牛棚雞舍。

【匯入與啟用】
1. 開啟（雙擊）桃花源.mcpack，用 Minecraft 匯入。手機：下載後用「分享／開啟方式」選 Minecraft。
2. 建立新世界：世界類型選「超平坦」，建議創造模式、開啟作弊（指令）。
   在「行為包」啟用「桃花源」。

【一鍵放置（建議）】
在世界中輸入以下指令（三行的座標要相同；座標 = 結構西北角最小 X/Y/Z，Y 一定要 -64）：
  /execute positioned 0 -64 0 run function taohua/prepare
  （等 5～10 秒讓區塊載入）
  /execute positioned 0 -64 0 run function taohua/build
  /execute positioned 0 -64 0 run function taohua/life     ← 選用：放出雞、狗、牛、羊、豬
  /function taohua/cleanup
prepare 建立 6 個常駐區塊（tickingarea），build 依序載入 20 個分件，cleanup 移除常駐區塊。
若某一塊沒出現，通常是區塊尚未載入：飛近那一區再執行一次 build（重複載入不會壞）。
life 會召喚 53 隻動物（院子裡的雞、狗窩旁的狗、村中散養的雞與 4 隻有名字的狗、牛棚的牛羊豬），
每執行一次就會多一批，只要執行一次。
※ 想放在別的位置，把三行的 0 -64 0 換成同一組座標即可（X、Z 自訂，Y 維持 -64）。
※ 世界中常駐區塊上限是 10 個，若已用掉 5 個以上，prepare 會有幾區建立失敗，請先移除舊的。

【逐件放置（結構方塊或指令）】
取得結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入結構名稱（旋轉 0°、無鏡像、完整性 100%）。
分件 taohuayuan_261103:tile_x<i>_z<j>（i = 0～3、j = 0～4）放在 (X+64i, -64, Z+64j)。例：
  /structure load taohuayuan_261103:tile_x0_z0 0 -64 0
  /structure load taohuayuan_261103:tile_x2_z3 128 -64 192
  /structure load taohuayuan_261103:tile_x3_z4 192 -64 256

【已知簡化】
- 原版沒有桃樹，用櫻花木與櫻花樹葉表現；桑樹用橡木幹＋叢林樹葉；水稻用水田裡的海草表現。
- 茅草屋頂用竹馬賽克階梯＋乾草塊；格扇門用打開的雲杉活板門。
- 水車、磨坊是靜態裝飾，沒有紅石機關；瀑布是崖面凹槽裡的水源柱，載入後會自然往前流成水簾落入潭中。
- 文中的村民（男女衣著、黃髮垂髫）沒有放；需要的話可以自己召喚村民。
- 箱子、木桶沒有放物品；告示牌、旗幟沒有文字。

【注意】
- 結構內的空氣會清除原地方塊，請在空曠的超平坦世界放置，預留 256 × 320 的範圍。
- 載入會把 Y=-64 那層也一起寫成基岩（與超平坦相同）。
- 不要在結構方塊按「儲存」覆蓋同名結構；只需匯入行為包，不需更換 db 或世界檔。
- 此檔是基岩版行為包，不是 Java 版 schematic，也不是完整世界。

方塊名稱與 state 依 Mojang bedrock-samples v1.26.60.5 官方方塊表檢查；行為包宣告最低版本 1.26.60。

所有草、花、花瓣、作物、竹子、蘆葦、睡蓮都有正確的支撐方塊；沙與礫石下方都有實心方塊。
