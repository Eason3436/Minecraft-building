倫敦大笨鐘與西敏市　使用說明
================================

【這是什麼】
倫敦西敏市（大笨鐘、國會大廈一帶）與泰晤士河兩岸的 1:1 實景還原。街道、每棟建築的輪廓與樓高、
屋頂形狀、泰晤士河、橋梁、公園、每一棵有登錄的樹、路燈、長椅、郵筒、公車站，全部依 OpenStreetMap
真實資料（透過 Overture Maps 2026-10-21.0 發行版取得）換算成方塊座標後生成。
國會大廈與西敏寺使用 OSM 志工建的 3D 部件模型（尖塔、角樓、飛扶壁、屋頂都分開登錄），所以外形和真的一樣複雜。
大笨鐘、倫敦眼、橋梁、議事廳等地標再另外手工精做外觀與內部。可用建築放置台放置。

【比例與範圍】
・比例 1:1（1 格 = 1 公尺），水平與高度相同。伊莉莎白塔 96 格高、倫敦眼 135 格高，世界高度放得下，不用縮小。
・範圍：北到特拉法加廣場（國家美術館前）、南到蘭貝斯橋、西到聖詹姆士公園藍橋、東到倫敦眼與郡政廳
  （再往東含滑鐵盧車站西半部）。約 1.47 km × 1.79 km。
・全區 寬 1472（X）× 深 1792（Z）× 高最多 145（Y）。共 644 分件（23 × 28，每件 64×64，高度依分件不同）。
・方位：沒有旋轉，-Z = 北（特拉法加廣場），+Z = 南（蘭貝斯），+X = 東（倫敦眼、南岸），-X = 西（聖詹姆士公園）。
・高度：結構 y=0～9 是地層，街道地面在 y=9（人站在 y=10）；泰晤士河水面在 y=3，比街道低 6 格，
  兩岸是花崗岩河堤與護牆。

【特製地標】
伊莉莎白塔（大笨鐘）
・塔身 13×13（實際 12 m 見方，取奇數讓鐘面置中），高 96 格；石灰岩垂直鑲板、細長窗、腰線。
・四面鐘：白色鐘盤、黑色刻度與指針（10:10）、金色方框；鐘面直徑 9 格（實際 7 m，放大一點才看得清指針）。
・鐘樓拱窗、金色稜線的鑄鐵尖頂、尖頂底部四面小山牆、頂端金色十字。
・內部：繞配重井的旋轉梯（從地面爬到鐘樓）、鐘機室（機芯與通往四面鐘的傳動桿）、鐘面室（背光燈）、
  鐘樓內的大笨鐘（青銅大鐘）與四口刻鐘、梯子通往艾爾頓燈（議會開會時點亮的燈）。入口在西面。
國會大廈（西敏宮）
・OSM 3D 部件：維多利亞塔、中央塔、數百根小尖塔、河岸立面、庭院；蜂蜜色石材＋深灰鑄鐵屋頂、哥德式細長窗。
・西敏廳：清空成大廳，石板地面，懸臂托梁木屋頂（深色橡木椽、托梁與天使）。
・中央大廳：中央塔下的八角廳，彩磚地面、金色吊燈、雕像座。
・下議院：綠色階梯長椅（兩側各 5 排）、樓座、議長座、議事桌與權杖。
・上議院：紅色長椅、金色王座華蓋、羊毛座。
西敏寺
・OSM 3D 部件：西立面雙塔、飛扶壁、尖塔、亨利七世禮拜堂。
・內部：中殿拱廊（石柱與尖拱）、高側窗、側廊頂、吊燈、詩班席、黑白棋盤地、高祭壇；北翼彩色玫瑰窗；西大門。
倫敦眼
・輪徑 120 m、總高 135 m；三管桁架輪框、23 m 主軸、64 條輪輻、32 座蛋形玻璃座艙（內有長椅）、
  陸地側 A 字支架與背拉索、伸入河面的登艙平台。輪面方向依 OSM 足跡。
橋
・西敏橋：綠色七孔拱、綠色欄杆、分水尖橋墩、橋上燈柱。
・蘭貝斯橋：紅色五孔、兩端方尖碑。滑鐵盧橋：五孔混凝土。
・亨格福鐵路橋（軌面高 7 格、桁架側梁、磚墩）＋兩側金禧人行橋（白色斜塔與斜拉索）。
・聖詹姆士公園藍橋、西敏碼頭等浮動碼頭。
其他
・特拉法加廣場：納爾遜紀念柱（46 m 柱＋銅像，花崗岩台座、四隻青銅獅）、兩座噴泉。
・白廳：騎兵衛隊、國宴廳、唐寧街 10 號黑門、和平紀念碑；國會廣場雕像群。
・查令十字與滑鐵盧車站的高架鐵路（磚拱高架、鐵軌）。

【街道與一般建築】
・2000 多棟建築依 OSM 輪廓與高度（無高度的依樓層數或用途推估）；屋頂分平頂、雙坡、四坡、金字塔、單坡、
  圓頂、孟莎、筒形，坡屋頂用樓梯方塊修邊。外牆依 OSM 顏色／材質對應：波特蘭石、紅磚、倫敦黃磚、灰泥、玻璃帷幕等。
・每 4 格一層樓板、窗格、平頂女兒牆；每棟一樓至少一扇面向人行道的門；室內放隱形光源方塊（light_block）防怪。
・道路依等級給寬度、白色中央虛線、斑馬線（含黃色閃燈柱）與號誌路口的白色標線、花崗岩路緣。
・約 3000 棵樹（倫敦梧桐為主，OSM 點位）、路燈、河堤海豚燈、長椅、紅郵筒、紅電話亭、公車站、雙層巴士與黑色計程車。

【與真實的差異（簡化之處）】
・地面統一為平地（實際有數公尺起伏）；泰晤士河水位固定在中潮。
・伊莉莎白塔塔身與鐘面略放大（見上），因塔與宮殿只差 6°，塔改為正南北方向。
・西敏廳、議事廳、中央大廳的位置依實際平面配置推定；其他建築內部只有樓板、門與光源，沒有家具。
・一般建築外牆材質多為依規則推定（OSM 只有部分建築登錄顏色材質）。
・地下鐵、地下道不做。

【匯入與啟用】
1. 雙擊「倫敦大笨鐘與西敏市.mcpack」匯入 Minecraft 基岩版。
2. 建立或編輯世界 → 行為包 → 啟用「倫敦大笨鐘與西敏市」，並開啟作弊（允許指令）。建議用「超平坦」世界。
3. 準備 1472 × 1792 的空地。原點 = 場地西北角（最小 X/Y/Z）。超平坦世界原點 Y 建議 -64。

【一鍵放置（建議）】
以原點 (0, -64, 0) 為例，依序執行（每次座標都要一樣）：
  /execute positioned 0 -64 0 run function london/prepare
  （等 3～5 秒讓區塊載入）
  /execute positioned 0 -64 0 run function london/build1
  （等 3～5 秒）
  /execute positioned 0 -64 0 run function london/build2
  ……依此類推到 build14（每段放 2 列共 46 個分件，聊天欄會顯示「第 N/14 段完成」）
  /function london/cleanup
每一段會建立 8 個常駐區塊（tickingarea，每個 192×128）；世界上限 10 個，請先確認世界中其他常駐區塊不超過 2 個。
若某一塊沒出現，通常是區塊尚未載入：走近那一區，用同樣座標再執行一次該段 build（重複載入不會壞）。
build1 是最北邊（特拉法加廣場），build14 是最南邊（蘭貝斯橋）。

【逐件放置（結構方塊或指令）】
取得結構方塊：/give @s structure_block → 放下 → 模式切「載入」→ 輸入結構名稱（旋轉 0°、無鏡像、完整性 100%）。
  分件 london_261118:tile_x<i>_z<j> 放在 (X+64i, Y, Z+64j)，i = 0～22、j = 0～27。
    例：/structure load london_261118:tile_x0_z0 0 -64 0
        /structure load london_261118:tile_x12_z15 768 -64 960   （大笨鐘所在分件）
完整載入順序寫在行為包的 functions/london/build1～build14.mcfunction 裡。

【注意】
  ・結構裡的空氣會清掉原地方塊，請放在空地上。
  ・只需匯入行為包，不需更換 db 或世界檔。這不是 Java 版 schematic，也不是完整世界。
  ・各分件高度不同（一般街區約 30～60 格，倫敦眼分件 145 格），都從同一個 Y 載入，地面會自動對齊。
