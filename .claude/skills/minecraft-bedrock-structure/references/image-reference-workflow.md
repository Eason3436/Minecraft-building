# 從參考圖片復刻

使用者給一張圖（照片、概念圖、遊戲截圖、手繪）要你「蓋成這樣」時，憑印象蓋幾乎一定失敗：比例跑掉、屋頂形式錯、材質變成預設的石磚。這份流程把「看圖」變成可寫進任務書的數字與清單，然後才建模，最後拿渲染圖回頭比對。

目錄：0 先講清楚能做到什麼｜1 讀圖與觀察清單｜2 估比例｜3 材質對應表｜4 分區成模組｜5 建模順序｜6 比對與修正｜7 範本

---

## 0. 先講清楚能做到什麼
- 復刻的是**辨識特徵**：量體比例、屋頂形式、開口節奏、主色與材質、標誌性元素。不是像素級、也不是照片級。
- 透視照片要先在腦中還原成正投影（正立面、側立面、平面），再量比例；不要直接照透視的線條蓋。
- 圖裡看不到的面（背面、室內）由你依風格補完，並在任務書註明「推測」。
- 圖中是曲面／斜線的地方，Minecraft 用階梯、半磚、逐格偏移近似，說明中誠實寫「已簡化」。

## 1. 讀圖與觀察清單

用 Read 工具讀圖後，**逐項寫下**（寫進任務書第 8 節）：

| 項目 | 要寫什麼 | 例 |
|---|---|---|
| 建築類型與用途 | 一句話 | 兩層町屋，一樓店面二樓住家 |
| 視角 | 正面／側面／45°／鳥瞰；看得到哪幾個面 | 45° 看到正面與左側 |
| 量體 | 幾個主要塊、各自相對大小與高低 | 主體 1 塊，右側附屬矮棚 1 塊 |
| 層數與層高比例 | 幾層、每層相對高度 | 2 層，一樓比二樓略高 |
| 屋頂形式 | 平／單坡／雙坡／四坡／歇山／攢尖／穹頂；坡度；有無翹角、老虎窗、煙囪、多層簷 | 雙坡，緩坡約 2:1，簷口外挑明顯，正脊有收頭 |
| 開口節奏 | 正面窗幾個、幾排、間距；門位置；有無格柵、百葉、陽台 | 二樓 4 扇格柵窗等距，一樓中央推拉門 + 兩側格柵 |
| 材質與顏色 | 每個部位的材質、顏色深淺 | 屋頂深灰瓦、牆白灰泥、木構深褐、基座灰石 |
| 標誌性元素 | 讓人一眼認出的東西 | 暖簾、燈籠、木格柵、屋頂上的鬼瓦 |
| 地形與景觀 | 平地／坡地／臨水；樹、圍籬、小徑、石燈 | 平地，前方石板路，左側一棵松 |
| 風格歸類 | 對應 `style-palettes.md` 哪一組 | 日式和風 |

觀察時的技巧：先看剪影（量體與屋頂），再看節奏（窗、柱），最後看材質。三件事分開寫，避免被細節帶跑。

## 2. 估比例

Minecraft 的尺是「格」，需要一個錨點把圖換算成格：
- 門高 = 2 格（最可靠的錨點）；成人高 ≈ 1.8 格；一層樓（含樓板）= 4–5 格；窗高 = 2 格；車輛長 ≈ 5 格。
- 用錨點量：門高 2 格，圖中門高 40 px → 1 格 = 20 px → 正面寬 500 px = 25 格。
- 使用者給了尺寸就以使用者為準，比例照圖；沒給就依錨點算，並取整到合理數（寬深 15–40、高 10–25 是常見範圍）。
- 屋頂坡度：量屋頂垂直高 : 水平深，換成每格升幾格（1:1、2:1 緩、1:2 陡）。
- 把算出的數字寫進任務書第 2 節（外框）與第 4 節（模組範圍）。

## 3. 材質對應表

每個部位對應 2–4 種基岩方塊（單一方塊不會像照片），查 `block-catalog.md` 與 `style-palettes.md`：

| 圖中部位 | 觀察到的材質/顏色 | 對應方塊（漸層比例） | state |
|---|---|---|---|
| 屋頂 | 深灰瓦、有排列紋 | `deepslate_tile_stairs` 7 / `polished_blackstone_brick_stairs` 2 / `deepslate_tile_slab` 屋脊 | `weirdo_direction` 朝脊 |
| 二樓牆 | 白灰泥 | `white_concrete` 4 / `white_terracotta` 3 / `smooth_quartz` 2 | — |
| 木構 | 深褐木 | `dark_oak_log` 柱 / `dark_oak_planks` 梁 / `stripped_dark_oak_log` | `pillar_axis` |
| 格柵窗 | 細直木條 | `dark_oak_fence` 或 `dark_oak_trapdoor open` | — |
| 基座 | 灰石 | `stone_bricks` 5 / `andesite` 3 / `cobblestone` 2 | — |
| 燈籠 | 紅白紙燈 | `shroomlight` + `red_stained_glass_pane` 或 `lantern` | `hanging` |

顏色抓不準時，優先對「明度」（深／中／淺）再對色相；Minecraft 沒有的顏色用最接近的陶瓦或混凝土。

## 4. 分區成模組

把圖拆成任務書第 4 節的模組表：主體量體、附屬量體、屋頂（每個量體一個）、門廊／陽台、標誌性元素、景觀。每個模組寫座標範圍與接口。

判斷順序：先量體（決定尺寸），再屋頂（決定高度），再開口（決定節奏），再細節與景觀。

## 5. 建模順序

按 `task-decomposition.md` 的 pass 制，但圖片復刻的順序更嚴格，因為每一步都要回頭對圖：

1. **量體**：只放主材整塊，把每個量體的外框、層高、屋頂剪影做出來 → 渲染 → 與圖並排看剪影對不對。剪影錯的話後面全白做。
2. **屋頂**：樓梯＋半磚、簷口、屋脊、翹角、煙囪 → 渲染比對坡度與簷。
3. **開口**：門、窗、格柵按圖的節奏放，數量與間距對齊 → 渲染比對正面。
4. **細節**：材質漸層、腰線、柱、窗框、標誌性元素（依 `detailing-techniques.md`）。
5. **室內**（圖看不到，依風格補）。
6. **景觀與照明**：圖中有的樹、圍籬、小徑、燈。

## 6. 比對與修正

渲染圖與參考圖並排（都用 Read 讀），列差異表：

| 面向 | 參考圖 | 目前渲染 | 差異 | 修正 |
|---|---|---|---|---|
| 剪影/比例 | 寬高 2:1 | 1.5:1 | 太高 | 二樓層高 5→4 |
| 屋頂 | 緩坡、簷外挑 | 陡坡、無簷 | 坡度、簷 | 改 2:1，外挑 1 格 |
| 開口 | 二樓 4 窗等距 | 3 窗 | 數量 | 補 1 扇，間距 3 |
| 材質色 | 牆白、頂深灰 | 牆灰、頂黑 | 明度 | 牆改 white_concrete 系 |
| 標誌元素 | 暖簾、燈籠 | 無 | 缺 | 加 wool 暖簾、lantern |

修一輪、再渲染、再比對；通常兩輪足夠。差異表與修正記錄寫進任務書第 9 節，交付說明裡註明「依參考圖復刻辨識特徵，已簡化之處：…」。
