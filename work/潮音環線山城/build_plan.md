# 潮音環線山城 任務書

> 狀態：**規劃完成，等待使用者確認後開工**（使用者要求「先做規劃」）。
> 開工後依第 4 節模組表逐項勾選；續跑時先讀本檔再看 `work/潮音環線山城/` 現況。

## 1. 需求摘要

- 使用者原話：「建造一個由鐵路圍繞靠海的山城」。
- 三個必備元素：
  1. **山城**：房子順著山坡一層層往上疊，靠石階與坡道串起來。
  2. **靠海**：山腳直接臨海，有港口、沙灘、燈塔。
  3. **鐵路圍繞**：一條可實際搭礦車繞行的環狀鐵路，把整座山城圈在裡面。
- 風格關鍵字（預設，可改）：**地中海彩色山城**（義大利五漁村式）——粉彩灰泥牆、赤陶瓦屋頂、石砌擋土牆、葡萄與檸檬梯田、石拱高架橋、沿海岸壁的鐵路。
- 參考圖：無。
- 交付：`structures/潮音環線山城/` 內 `潮音環線山城.mcpack`、`_使用說明.txt`、`_整體渲染.png`、`_內部剖視.png`。

## 2. 尺寸與座標

- 外框：寬 X=256 × 高 Y=128 × 深 Z=256（NBT 每件 size=[64,128,64]）。
- 分件：4×4 = **16 分件**，id `p_<ix>_<iz>`（ix、iz = 0..3），附 `/function` 一鍵放置（比照「幻境海港山城」）。
- 原點：最小角。方位：**北 = −Z（山背）、南 = +Z（大海）**，東側 +X 為海灣。
- 高度基準：海面 y=20；海床 y=8–18；**鐵路軌面 y=30（道床頂 y=29）全線等高**；山頂 y≈108；最高建物尖頂 ≤ y=124。
- namespace：`chaoyin_loop_261111`。
- 目標版本／mojang-blocks.json 版本／block_version：開工時下載官方表後填入。
- 建議放在超平坦或海面高度相近的海邊；主要層範圍外不動。

## 3. 拆解決策

- 耦合度判斷：**單體切分件**（地形、街道、鐵路互相咬合，必須在同一個 256×128×256 陣列上建完再切 64×64），內部再**依模組函式**分工。
- 鐵路屬「機制優先」：先做一段最小單元（直線＋動力軌＋一個轉角＋一段斜切之字線）驗證 `rail_direction` 與供電，再鋪全線。
- 房屋用參數化生成器（5 種屋型 × 配色 × 樓層數 × 面向），避免 60 棟各寫一次；地標建物各自一個函式。
- 鐵路含動力軌與紅石塊供電，屬紅石相關：**開工前先完整讀 `docs/紅石犯錯紀錄.md`**，並依其檢查清單執行。

### 4.2 環狀鐵路（核心）

- 路線：圓角矩形，**x=24…231、z=28…199**，四個角各用 24 格的 45° 之字線削角；一圈約 700 格。
- 斷面：**雙軌 5 格寬**（邊帶／軌 A／中央帶／軌 B／邊帶），沿用本專案「霧杉雙軌鐵道模組」的斷面慣例，可雙向對開。
- 全線軌面 y=30 不爬坡，靠地形起伏製造變化：

| 區段 | 位置 | 形式 |
|---|---|---|
| 南段・海堤線 | z=199，x=48…207 | 高 10 格的石砌海堤，面海側拱洞（可從下城穿越到沙灘與碼頭），是全線主視覺 |
| 西段・溺谷高架橋 | x=24，z=72…140 | 多孔石拱高架橋，跨河口溺谷，橋下可行小船 |
| 北段・北嶺隧道 | z=28，x=96…176 | 木框＋石拱隧道，兩端洞門，內部每 8 格一盞燈 |
| 北段・山後路塹 | z=28，x=48…96 | 開挖路塹＋山後小站 |
| 東段・岸壁線 | x=231，z=52…175 | 貼海崖的岩棚與明隧道（半開放拱廊，朝海開窗） |
| 四個削角 | — | 路堤或短橋，之字線雙軌 |

- 供電：每 24 格一對動力軌（下方紅石塊常時供電），站內用一般鐵軌＋動力軌停靠段與按鈕發車。
- 車站：
  - **海濱總站**（南，約 x=112…150，z=186…199）：兩層站房、鐘塔、鑄鐵雨棚月台、候車室、售票口、站前廣場接市場。
  - **山後小站**（北，約 x=56…80，z=22…34）：木造小站＋號誌樓。
  - **機務段**（東南，約 x=176…204，z=176…192）：兩線車庫、水塔、煤台、一列靜態蒸汽列車模型（側線，不擋主線）。
- **斜面纜索鐵道**：從總站後方 (128,30,182) 直上教堂廣場 (128,72,138)，全程動力軌，可搭礦車上下山。

## 7. 細節檢查清單

- [ ] 岩壁至少 4 種方塊漸層，海崖有淺色層理與苔痕
- [ ] 擋土牆有扶壁、排水口、爬藤，不是整片平牆
- [ ] 房屋：牆面 3 種同色系漸層、窗框＋百葉＋花箱、屋簷外挑 1 格、煙囪
- [ ] 相鄰房屋顏色與高度不重複，屋脊方向交錯
- [ ] 每條街有燈、每個廣場有焦點（噴泉／井／雕像／樹）
- [ ] 鐵路：軌枕節奏、道床碎石、圍籬、號誌、隧道洞門、橋墩分水尖
- [ ] 每個房間 家具＋光源＋小物
- [ ] 樹非正方形，至少 4 種樹形
- [ ] auto_connect 玻璃板／牆／柵欄
- [ ] stats：distinct_blocks ≥ 40；扣除地形與水後最大單一方塊 ≤ 60%

## 8. 驗收條件

- [ ] **鐵路閉合成環**：程式沿軌道走一圈回到起點，兩條軌都通；無斷軌、無錯向、每段動力軌間距 ≤ 26 格且下方有紅石塊
- [ ] 環線走廊淨空（軌面上方 3 格無方塊侵入，隧道淨高足夠）
- [ ] 斜面纜索鐵道上下可通
- [ ] 山城確實被環線包圍；南側與東側臨海
- [ ] 從總站步行可達：下城 → 中城 → 上城 → 山頂（路徑搜尋驗證，階高 ≤ 1）
- [ ] 16 分件各自 NBT 重新解析通過，接縫無錯位
- [ ] 渲染圖打開檢視：無浮空、無穿模、入口暢通
- [ ] 交付目錄恰好四個檔案；放置台報到完成
- [ ] 無法遊戲實測時，說明檔註明「格式驗證通過，尚未在遊戲內實測」

## 9. 待使用者確認的事項（都有預設，回「好」即照預設開工）

1. **風格**：預設「地中海彩色山城（五漁村式）」。其他可選：台式九份風（紅燈籠、石階、茶樓）／日式海街（黑瓦木屋、江之電式路面電車感）。
2. **規模**：預設 256×256×128、16 分件。可改小為 192×192（9 分件，房屋約少四成）。
3. **鐵路**：預設雙軌環線＋斜面纜索鐵道、可實際搭礦車。可改單軌（路基較窄、較不搶戲）。
