# 生態系車站合集　任務書

## 1. 需求摘要
使用者原話：「設計MC各個生態係各一種 高架和地下車站 和鐵路　大小不要太大」。
→ 16 個生態系，每系一座高架車站、一座地下車站，並附同風格的鐵路段。小巧、易放置，可互相串接。

## 2. 生態系清單（id / 中文）
plains 平原、desert 沙漠、snowy 雪原、jungle 叢林、taiga 針葉林、birch 樺木林、darkforest 黑森林、swamp 沼澤、
mangrove 紅樹林、savanna 莽原、badlands 惡地、mushroom 蘑菇島、ocean 海洋、cherry 櫻花林、palegarden 蒼白之園、nether 下界（緋紅森林）

## 3. 拆解決策（模組化，靠數字約定接合）
每個生態系 5 件，全部共用同一個斷面與高度系統，所以任何兩件都能沿 X 方向首尾相接：

| 件 | id 後綴 | 尺寸 X×Y×Z |
|---|---|---|
| 地下車站 | `_ug_station` | 24×30×13 |
| 隧道段 | `_ug_track` | 16×30×13 |
| 升降坡道（地下→高架） | `_ramp` | 32×30×13 |
| 高架段 | `_el_track` | 16×30×13 |
| 高架車站 | `_el_station` | 24×30×13 |

接口約定（結構內座標）：
- 地表頂面方塊 y=9（玩家站 y=10）。y0–8 是地層（含泥土/石頭），所以載入時用 `~ ~-10 ~` 會剛好嵌進地面。
- 雙軌：z=2、z=10。地下軌面 y=2（道床 y=1），高架軌面 y=17（道床 y=16）。
- 島式月台 z=3–9；月台面與道床同高。
- 坡道：x0–4 在 y=2、x27–31 在 y=17，中間「升、升、平」重複，共升 15 格；坡道上全是動力軌、下墊紅石塊。
- 動力：車站兩端 x=2、x=21 各一格動力軌（墊紅石塊）；x=10–13 為過站停車段，由月台拉桿（x=12,z=3 / z=9）供電，預設開＝直通。
  鐵路段 x=4、x=12 各一格動力軌（墊紅石塊）。各件動力段彼此不相鄰。
- 上方空氣：每欄最高方塊上 3 格以內是空氣（保證軌道淨空），再往上寫結構空位，不會清掉原地形的樹。

展示：每個生態系一條示範線（西→東：地下站、隧道、坡道、高架段、高架站，共 112 格），16 條平行排列，z 間距 16。

## 4. 座標規劃
高架站：橋墩 x=2/11/21（z0–1、z11–12），甲板 y16，月台樓梯在島中央 z5–7、x10–15 往西下到地面，甲板開口 x12–15；
屋頂柱 z0/z12 於 x=2,8,15,21，簷口 y21；屋頂依風格（山形/低坡/平頂/和風翹簷/蘑菇圓頂/拱頂）。
地下站：月台廳 y2–6，天花 y7，樓梯 x15→x8 往西上到地面（y2→y9），地面出入口亭 x6–14、z3–9。

## 5. 調色盤
每個生態系各自一組（石作、木作、屋頂、月台地板、月台邊、道床、窗、燈、壁帶、植物、樹）。見 gen.py 的 BIOMES。

## 6. 細節清單
- 牆面至少 3 種同色系方塊混合；屋頂用樓梯＋半磚；月台有長椅、植栽、吊燈；地下站壁面有腰帶、壁燈、壁柱、天花梁。
- 高架橋墩＋橫梁＋拱腋；地面有該生態系植物；地下段地表有小樹。
- 雪原屋頂與地面積雪；海洋為海底玻璃隧道；下界用黑石與緋紅木。

## 7. 驗收
- 80 件 NBT 重新解析逐格比對；方塊與 state 對照官方表。
- 每件雙軌逐格：軌道存在、下方支承、上方 2 格淨空、坡道方向正確。
- 月台→地面步行可達（BFS）。重力方塊下方有支撐，吊燈上方有方塊。
- 整體渲染（16 條示範線）＋內部剖視（地下站剖開、高架站去頂）。
