# 吉薩大金字塔（古夫金字塔）任務書

## 1. 需求摘要
使用者：「還原埃及吉薩大金字塔」。協調者補充：盡量貼近真實比例與內部結構（國王墓室、王后墓室、大走廊等），可含周邊。
決定：**1 格 = 1 公尺，1:1 實尺**，還原成剛完工時的樣貌（白色圖拉石灰岩外殼完整），內部通道依考古實測配置。
顯示名稱「吉薩大金字塔」，namespace `giza_261118`，function 前綴 `giza/`。

## 2. 尺寸與原點
- 全區 384（X）× 384（Z）× 190（Y），切 6×6 = 36 分件（每件 64×H×64，H 依該件最高方塊裁切，最少 G+8）。
- 地面（鋪石頂面）y=G=40；金字塔第 k 層在 y=G+1+k，k=0..146（共 147 層＝146.6 m）。
- 金字塔中心 (PX,PZ)=(140,140)，底邊 231 格（實測 230.33 m），x/z 25..255。北＝−Z。
- 每層半寬 hw(k)=round(115×(1−k/146.6))，斜率約 51.84°。
- 地下室底在 m=−30（y≈11），結構最低 y≈5；build function 以 `~ ~-40 ~` 載入，使玩家腳下＝地面。

## 3. 拆解決策
單一大陣列（模組靠座標約定），分 pass：
1. 地形：岩盤（end_stone/砂岩）、沙地＋微沙丘、鋪石台、圍牆。
2. 金字塔本體：核心（砂岩混砌按層變化）＋外殼兩格（平滑石英，外緣樓梯）＋金色塔頂（推測）。
3. 內部：所有空腔先記在 void 標籤陣列，挖空後依標籤給內襯（細石灰岩／花崗岩／粗岩）。
4. 周邊：葬祭殿、參道、三座王后金字塔（含內部）、衛星金字塔 G1-d、五個船坑（南側兩坑含古夫船）、東／南馬斯塔巴墓群。
5. 照明（現代參觀用：頂部嵌燈）、梯子、扶手、標示。
